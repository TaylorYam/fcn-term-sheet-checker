## 3. 允許值與 Natixis 差異

| 欄 | 值 | 意義 |
|---|---|---|
| KO(Freq) | `D` | 每日觀察（`從第k個配息觀察期間結束日(含)到最終評價日(不含)之每一預定交易日每日觀察`；NX1、NX2、NX5–NX8） |
| | `P` | 每期觀察（第 12(7) 項自動提前到期觀察日表；NX3、NX4） |
| KO(memo) | `Y`／`N` | 記憶式（`皆曾經高於或等於`）／非記憶式 |
| KI(Freq) | `-` 或空白 | 無 KI（NX3、NX5） |
| | `AM` | 到期觀察（`觸及事件判定日：最終評價日`；NX2、NX4、NX6、NX8） |
| | `D` | 每日觀察（`觸及事件判定期間之各預定交易日`；NX7） |
| | `P` | 每期觀察（`觸及事件判定期間之各配息觀察期間結束日`；NX1） |
| 期初定價 | `開盤價`／`收盤價`／`VWAP`／空白 | 說明書沒寫，不核對；`VWAP` 時價格欄照共用規則（Issue #122、#246）不比對、通過後覆寫（NX5） |

- **標的順序**：連結標的表與表上順序相同（7 份成立），照共用規則依順序比對，不加 `any_order_issuers`。
- **KI 價格欄**：表上 `UL_n_下限價` 對應說明書的 `界限價格`（KI 樣本都成立）。
- **`UL_n_Memo` 不核對**（2026-10-15 確認）：說明書是整檔判斷記憶式；表上逐檔值有 3 份和 `KO(memo)` 對不起來（§6）。
- 單位面額：USD 10,000、JPY 1,000,000、AUD 10,000（= 審查標準預設值）。
- 表上執行價、下限價可能存 5 位以上小數，四捨五入到 4 位後與說明書相等（共用規則）。
- 標的價格幣別可和承作幣別不同（NX6：AUD 計價、美股；Issue #170）。

## 4. 比價日填法（共用規則見[參考條件表格式](reference-sheet.md) §4）

| 型態 | 填法 | 說明書日期 |
|---|---|---|
| `D` | `比價日_{Non-Call}` 與 `比價日_{天期}` | 開始：日期表第 Non-Call 期 `配息觀察期間結束日`（= 第 12 項 `從第k個配息觀察期間結束日(含)` 那一天）；最後：最終評價日（= 日期表末列結束日） |
| `P` | 從 `比價日_{Non-Call}` 填到 `比價日_{天期}` | 第 12(7) 項觀察日表每列的 `自動提前到期觀察日(t)`；期別 = 同列 `自動提前到期日(t)` 在配息日表的期別（**觀察日表的 `t` 不是期別**，NX3 只有 1 列 `t = 1`、對應第 6 期）。觀察日表列數須 = 天期 − Non-Call + 1，否則轉人工覆核 |
| Non-Call = 天期 | 只填 `比價日_{天期}` | 最終評價日（NX3） |

探勘用的表比價日欄全部空白（待回填），無法用表驗證；填法依條文推得，實作後以回填結果請作業人員確認。

## 5. 不核對的欄位

`TS/IIS完成檢核`、`交易日期`、`Product`、`私銀註記`、`UF`、`分公司_n`、`分公司_n_承作金額`、`下一比價日`、`期初定價`、`UL_n_Memo`、無表頭欄（同其他上手；`期初定價` 因說明書沒寫而不核對）。
