## 3. 允許值與 BBVA 差異

| 欄 | 值 | 意義 |
|---|---|---|
| KO(Freq) | `D` | 每日觀察（`自動提前贖回觀察期間內之每個預定交易日`；BV1、BV3–BV5） |
| | `P` | 每期觀察（第 12(9) 項自動提前贖回觀察日表；BV2）；只支援記憶式（KO 每期非記憶式是不支援樣態） |
| KO(memo) | `Y`／`N` | 記憶式（`最佳表現值`）／非記憶式（`最差表現值`） |
| KI(Freq) | `-` 或空白 | 無 KI（BV1、BV3） |
| | `AM` | 到期觀察（`（下限值）`；BV2、BV4、BV5）。KI `D`、`P` 是不支援樣態 |
| 期初定價 | `開盤價`／`收盤價`／`VWAP`／空白 | 說明書沒寫，不和說明書比、只檢查是允許值；`VWAP` 時價格欄照共用規則（Issue #122、#246）不比對、通過後覆寫（BV4） |

- **標的順序**：BV2 說明書（第 9 項、價格表）順序和表上不同、同一組代碼；其他 4 份相同。**`any_order_issuers` 加 `BBVA`**，依代碼配對（同 Citi、JPM、GS；2026-10-15 確認）。
- **KI 價格欄**：表上 `UL_n_下限價` 對應說明書的 `下限值X 期初價格`（KI 樣本都成立）。
- **`UL_n_Memo` 不核對**（2026-10-15 確認）：說明書是整檔判斷記憶式；表上 BV2、BV3 有值，其他空白。
- 單位面額：USD 10,000、JPY 1,000,000（= 審查標準預設值）。
- 表上執行價、下限價可能存 5 位以上小數，四捨五入到 4 位後與說明書相等（共用規則）。
- 標的價格幣別可和承作幣別不同（BV1：JPY 計價、美股；Issue #170）。

## 4. 比價日填法（共用規則見[參考條件表格式](reference-sheet.md) §4）

| 型態 | 填法 | 說明書日期 |
|---|---|---|
| `D` | `比價日_{Non-Call}` 與 `比價日_{天期}` | 開始：第 12 項 (10) 自動提前贖回觀察期間起日（= 日期表第 Non-Call 期 `終止日(含)`）；最後：贖回評價日（= 日期表末列終止日） |
| `P` | 從 `比價日_{Non-Call}` 填到 `比價日_{天期}` | 第 12(9) 項表每列的 `自動提前贖回觀察日`（期別 = 同列 `自動提前贖回日` 在配息日表的期別），最後一期為贖回評價日（表只到天期 − 1 期）；表列數須 = 天期 − Non-Call，否則轉人工覆核 |

探勘用的表比價日欄全部空白（待回填），無法用表驗證；填法依條文推得，實作後以回填結果請作業人員確認。

## 5. 不核對的欄位

`TS/IIS完成檢核`、`交易日期`、`Product`、`私銀註記`、`UF`、`分公司_n`、`分公司_n_承作金額`、`下一比價日`、`UL_n_Memo`、無表頭欄（同其他上手）。`期初定價` 因說明書沒寫，只檢查是允許值、不和說明書比（§3）。

- `UL_n_Memo`：BV2、BV3 有值，其他空白；不核對。
