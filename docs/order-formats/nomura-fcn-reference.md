## 3. 允許值與 Nomura 差異

| 欄 | 值 | 意義 |
|---|---|---|
| KO(Freq) | `D` | 每日觀察（`自…起（含）至最終評價日止（含）之各預定交易日`） |
| | `P` | 每期觀察（第 11 項 (6) 自動提前出場決定日表） |
| KO(memo) | `Y`／`N` | 記憶式／非記憶式（單一標的填 `N`，NR1、NR4） |
| KI(Freq) | `-` 或空白 | 無 KI（沒有下限觸發事件） |
| | `AM` | 到期觀察（`下限觸發決定日：最終評價日`；NR4） |
| | `D` | 每日觀察（`自交易日起（不含）至最終評價日止（含）之各預定交易日`；NR7） |
| | `P` | 每期觀察（第 11 項 (6) 下限觸發決定日表；NR1）。Nomura 支援樣態表沒有列 `ki_periodic`，照常核對 |

- **年利率**：表上 `Coupon p.a. (%)` 和說明書第 14 項情境一、二的年化報酬率比；說明書條款只寫每期配息率，另核 = 年利率 ÷ 12 四捨五入到 4 位（[核對規則](../rules/nomura-check-rules.md) §3.3；Issue #297）。
- **到期日**：取第 11 項 (4) 預定到期日（`即最終評價日後之第三個…營業日`）；條文會跳過該營業日所在地的假日。NR6 表上到期日早 1 天（少算一個美國假日），2026-10-15 確認是表填錯，照常判不一致。
- **期初定價 `VWAP`**（NR6）：說明書沒有寫期初定價方式，期初定價欄不核對；價格欄照共用規則（Issue #122）不比對，整份通過或人工放行後以說明書價格覆寫。NR6 表上進場價空白、執行價與 KO 價四捨五入到 4 位後本來就等於說明書。期初定價 `開盤價`（NR4、NR7）同樣不核對期初定價欄，價格照常比對。
- **KI 價格欄**：表上 `UL_n_下限價` 對應說明書的 `下限觸發價`（NR1、NR4、NR7 成立）。
- **Non-Call = 天期的 P 型**（NR2）：只在最終評價日觀察 KO；表上 `KO(Freq)` = `P`、`Non-Call(月)` = 天期、KO(%) 與 KO 價照說明書（說明書有自動提前出場價）。比價日只填最後一格。
- 單位面額：USD 10,000、JPY 1,000,000、AUD 10,000（= 審查標準預設值）。
- `K(%)` 可為非整數（NR1、NR2）；表上執行價可能存 5 位以上小數，四捨五入到 4 位後與說明書相等。
- 標的價格幣別可和承作幣別不同（NR1、NR3：AUD 計價、日股；Issue #170）。

## 4. 比價日填法（共用規則見[參考條件表格式](reference-sheet.md) §4）

| 型態 | 填法 | 說明書日期 |
|---|---|---|
| `D` | `比價日_{Non-Call}` 與 `比價日_{天期}` | 開始：第 7 項 KO 起日（= 日期表第 Non-Call 期 `觀察期間終止日(含)`）；最後：最終評價日（= 日期表末列觀察期間終止日） |
| `P` | `比價日_{Non-Call}` 到 `比價日_{天期}` 每一期 | 日期表各期 `自動提前出場決定日`（`不適用` 的期別不填）；Non-Call = 天期時只填最後一格（NR2） |

探勘用的表比價日欄全部空白（待回填），無法用表驗證；填法依條文推得（同 JPM），實作後以回填結果請作業人員確認。

## 5. 不核對的欄位

`TS/IIS完成檢核`、`交易日期`、`Product`、`私銀註記`、`UF`、`分公司_n`、`分公司_n_承作金額`、`下一比價日`、`UL_n_Memo`、`期初定價`（Nomura 說明書沒有出處）、無表頭欄（同其他上手）。
