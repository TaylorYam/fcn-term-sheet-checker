## 3. 允許值與 SG 差異

| 欄 | 值 | 意義 |
|---|---|---|
| KO(Freq) | `D` | 每日觀察（§8 `…觀察期間：自…起至最終評價日…每一個預定交易日`） |
| | `P` | 每期觀察（§8 `若於任一評價日i (i=k-n)`）；**無自動提前出場的商品也填 `P`**（SG6） |
| KO(memo) | `Y`／`N` | 記憶式（§8 有 `記憶事件：`）／非記憶式 |
| KI(Freq) | `-` | 無 KI（§8 沒有 `下限價：` 行，到期贖回以執行價判） |
| | `AM` | 到期觀察（兩款，以下限價判） |
| | `D` | 每日觀察（三款，`每一個預定交易日（「觀察期間」）`）；SG4 樣本 |
| | `P` | 每期觀察（三款，`每一個評價日i`）；只有舊版面樣本 SG5 |

- **無自動提前出場**（SG6；2026-10-13 確認照此對照）：說明書沒有自動提前出場事件、自動提前出場價與自動提前出場日；表上 `KO(Freq)` = `P`、`KO(%)` = `100`、`Non-Call(月)` = 天期、`UL_n_KO價` = 進場價，比價日只填最後一格（同 BARC「Non-Call = 天期」慣例）。
- **KO P 與 KI D 同時出現**（SG4）：兩欄各自判定（2026-10-13 確認）。
- 期初定價 `VWAP`（SG2）：照共用規則，`UL_n` 四個價格欄不比對，整份通過或人工放行後以說明書價格覆寫（Issue #122）。SG2 表上的值本來就等於說明書。期初定價 `開盤價`（SG4）：說明書沒有對應字樣，價格照常比對。
- 單位面額：USD 10,000、JPY 1,000,000、CNH 100,000（= 審查標準預設值）。
- 承作幣別 `CNH`：封面寫 `境外人民幣`，英文名稱寫 `CNY`。
- `K(%)` 可為非整數（SG6 `87.65`）；表上執行價可能存 5 位以上小數（例 `1234.56785`），四捨五入到 4 位後與說明書相等。

## 4. 比價日填法（共用規則見[參考條件表格式](reference-sheet.md) §4）

| 型態 | 填法 | 說明書日期 |
|---|---|---|
| `D` | `比價日_{Non-Call}` 與 `比價日_{天期}` | 開始：§8 觀察期間起始日（= 日期表第 Non-Call+1 期起始日）；最後：日期表末列終止日（= 最終評價日） |
| `P` | `比價日_{Non-Call}` 到 `比價日_{天期}` 每一期 | 日期表各期評價日（`不適用` 的期別填 `-`） |
| 無自動提前出場 | 只有 `比價日_{天期}` | 日期表末列評價日（= 最終評價日） |

6 份樣本的比價日全部符合此填法。

## 5. 不核對的欄位

`庫存狀態`、`當日比價`、`Product`、`私銀註記`、`UF`、`UL_n_Memo`、`期初定價`、無表頭欄（同其他上手，期初定價為 SG 新增的不核對欄）。`發行機構` 只用來確認列屬於 SG。

## 6. 探勘時發現的表上問題（2026-10-13）

- SG5 的 `UL_2` 四個價格皆為說明書的同一比例（約 0.978；該標的在交易後有除權息調整）：依 [BNP 核對規則](../rules/bnp-check-rules.md) §3.4 的共用規則，同一檔標的各價格差同一比例 → 轉人工覆核，表上值不改。
