## 1. 結構

與其他上手相同（版面見[參考條件表格式](reference-sheet.md) §1，每列一檔）。商品代號前 3 碼為 `148`（`config/issuer_prefixes.toml` 已登記 `GS`，支援樣態表 `GS = ["ko_periodic_memory", "ko_periodic", "ki_periodic", "non_call_equals_tenor"]`）。

探勘用的參考條件表是作業人員提供的公司原始待建檔格式（`data/orders/核對表格式..xlsx`，工作表 `ELN待建檔_測試`，5 列 GS，與 GS1–GS5 全部對上；`ISIN Code`、`發行日`、`比價日_n` 為待回填的空白；沒有 `發行機構` 欄）。

實作時要登記：

- `config/reference_sheet.toml` `[issuer_values]`：`GS = "GS"`（`發行機構` 欄的寫法，2026-10-15 作業人員確認；待建檔表沒有這欄時以商品代號前 3 碼判定）。
- `config/reference_sheet.toml` `[underlyings] any_order_issuers`：加入 `GS`（§3）。
- `src/fcn_checker/issuers.py`：GS 範本（`gs-zh-pd`、投資人須知 `gs-zh-iis`）。

## 2. 欄位對照

| Excel 欄 | 標準欄位 | 說明書來源（見[範本規格](../templates/gs-zh-product-description.md)） |
|---|---|---|
| TDCC Code | `product_code` | 第 1 頁 `受託機構商品代號為`（另有 3 處 TDCC 交叉驗證） |
| ISIN Code | `isin` | 第 1 頁中文名稱括號 `ISIN:`（表上空白時回填） |
| 單位面額 | `denomination` | 第一章第 6 項 `每單位面額:` |
| 計價幣別（承作幣別） | `currency` | 第 1 頁第 6 項 `計價幣別:`（`美元`→USD、`日圓`→JPY、`人民幣`→CNH；對照表 `[currency]`）；第一章第 5 項 `美元（USD）` 交叉驗證（人民幣寫 `CNY`，視為 CNH） |
| 交易日／發行日／到期日 | `trade_date`／`issue_date`／`maturity_date` | 第一章第 13 項 (2) 交易日／(3) 發行日／(5) 到期日 `現預定為…`（發行日表上空白時回填） |
| 最終比價日 | `final_valuation_date` | 第 13 項 (4) 評價日（= 觀察時程表末列結束日） |
| KO(%) | `ko_pct` | 第 15 項價格表表頭 `提前出場價格(i)(初始參考價格(i)之Y%)` |
| KO(Freq) | `ko_observation` | 第 16 項 `「提前出場觀察日」` 寫法（範本規格 §4.1；只有 D） |
| KO(memo) | `ko_memory` | 第 16 項 `記憶提前出場事件(i)` 寫法（範本規格 §4.2；單一標的 = N） |
| K(%) | `strike_pct` | 第 15 項 `「執行價格(i)」:初始參考價格(i)之X%`（可為非整數，例 `81.25`）；表頭交叉驗證 |
| KI(%) | `ki_pct` | 第 15 項 `「下限觸發價格(i)」:初始參考價格(i)之Z%`；無 KI 時 Excel 為空白或 `-` |
| KI(Freq) | `ki_type` | 第 15 項到期買回寫法與 `「下限觸發事件」` 定義（範本規格 §4.4） |
| Coupon p.a. (%) | `coupon_pa_pct` | 第 14 項 `指年利率X% / 12` 的 X |

| Non-Call(月) | `first_callable_period` | 第 16 項 `自第k個觀察期間結束日開始` 的 k |

| 期初定價 | `initial_pricing` | 第 15 項 `初始參考價格(i)…` 一句：開盤價格 → `開盤價`、成交量加權平均價格 → `VWAP`、交易日之參考價格（參考價格 = 收盤價格）→ `收盤價`（範本規格 §4.7；比照 Citi，2026-10-15 確認） |

## 3. 允許值與 GS 差異

| 欄 | 值 | 意義 |
|---|---|---|
| KO(Freq) | `D` | 每日觀察（`「提前出場觀察日」指自第k個觀察期間結束日開始（含）至評價日結束（不含）…`） |
| | `P` | GS 不支援樣態（`ko_periodic`、`ko_periodic_memory`），辨識時攔下 |
| KO(memo) | `Y`／`N` | 記憶式／非記憶式（單一標的填 `N`，GS5） |
| KI(Freq) | `-` 或空白 | 無 KI（沒有下限觸發價格；GS5） |
| | `AM` | 到期觀察（只在評價日比下限觸發價格；GS3、GS4） |
| | `D` | 每日觀察（`「下限觸發觀察期間」指自交易日開始（不含）至評價日結束（含）`；GS1、GS2） |
| | `P` | GS 不支援樣態（`ki_periodic`），辨識時攔下 |
| 期初定價 | `開盤價`／`收盤價`／`VWAP`／空白 | 說明書寫明（§2）；照共用規則（Issue #246） |

- **標的不看順序（2026-10-15 確認，比照 Citi、JPM）**：GS 說明書價格表的標的依**彭博代碼字母／數字順序**排列，參考條件表依交易時的順序填；4 份多標的樣本（GS1–GS4）表上順序都和說明書不同（代號與各價格都對得上）。GS 加入 `[underlyings] any_order_issuers`：表上與說明書是同一組彭博代號（數量相同、沒有重複）就通過，各價格欄依代號找到說明書那一檔再比；代號集合不同、數量不同、有重複時照常判不一致。回填（VWAP 覆寫）寫到表上**相同代號**那一格；投資人須知標的代號（B11）同樣依代號配對。
- **期初定價**（2026-10-15 確認，與 Issue #246 同步、比照 Citi）：表上有值 → 和說明書比，不同判不一致；表上空白 → 說明書寫 VWAP 時當 VWAP 商品處理（價格欄不比對、通過後依代號以說明書覆寫；投資人須知價格改和說明書比），寫開盤價／收盤價時各標的價格照常比對；說明書寫法讀不到或不在範本規格 §4.7 → 轉人工覆核（無法判斷是不是 VWAP）。「期初定價」欄本身不回填。
- **KI 價格欄**：表上 `UL_n_下限價` 對應說明書的 `下限觸發價格(i)`（GS1–GS4 成立）。
- **人民幣**：表上 `CNH`；說明書中文 `人民幣` 對到 CNH，第一章第 5 項與英文名稱的 `CNY` 視為 CNH（2026-10-15 確認，比照 SG）。
- 單位面額：USD 10,000、JPY 1,000,000、CNH 100,000（= 審查標準預設值）。
- `K(%)` 可為非整數（GS4）；表上執行價可能存 5 位以上小數，四捨五入到 4 位後與說明書相等。
- 標的價格幣別可和承作幣別不同（GS1：CNH 計價、美股；Issue #170）。

## 4. 比價日填法（共用規則見[參考條件表格式](reference-sheet.md) §4）

| 型態 | 填法 | 說明書日期 |
|---|---|---|
| `D` | `比價日_{Non-Call}` 與 `比價日_{天期}` | 開始：觀察時程表第 Non-Call 期 `觀察期間結束日(含)`（= 第 16 項 `自第k個觀察期間結束日開始` 那一天）；最後：評價日（= 觀察時程表末列結束日） |

探勘用的表比價日欄全部空白（待回填），無法用表驗證；填法依條文推得（同 JPM、Nomura 的 D 型），實作後以回填結果請作業人員確認。

## 5. 不核對的欄位

`TS/IIS完成檢核`、`交易日期`、`Product`、`私銀註記`、`UF`、`分公司_n`、`分公司_n_承作金額`、`下一比價日`、`UL_n_Memo`、無表頭欄（同其他上手）。

## 6. 探勘時發現的表上狀況（2026-10-15）

- GS1–GS4：表上 `UL_n` 順序和說明書不同（GS 依代號配對，§3）。
- GS2：一檔日股的說明書初始參考價格與執行／提前出場／下限觸發價格都剛好是表上的 **2 倍**（說明書情境 4 也用同一個價格）；2026-10-15 作業人員確認是表上錯。照現行共用規則：同一檔價格欄全部差同一比例 → 轉人工覆核並寫出比例（疑似分割調整，Issue #222），不改程式。
- GS3（VWAP）：表上 `UL_n_進場價` 空白，執行價、下限價存多位小數，四捨五入到 4 位後與說明書相符。
- GS4：表上執行價存多位小數（K % 非整數），四捨五入到 4 位後相符。
- GS1：表上 `CNH`，說明書英文 `CNY`（§3）。
- GS2：表上 `KO(memo)` = `Y`，但其中一檔 `UL_n_Memo` = `N`；`UL_n_Memo` 不核對，`KO(memo)` 與說明書相符。
