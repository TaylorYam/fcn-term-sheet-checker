- 狀態：規格（待實作，Issue #233）。共用的版面、配對、回填規則見[參考條件表格式](reference-sheet.md)，本文件只寫 JPM 的說明書來源與差異

## 1. 結構

與其他上手相同（版面見[參考條件表格式](reference-sheet.md) §1，每列一檔）。商品代號前 3 碼為 `076`（`config/issuer_prefixes.toml` 已登記 `JPM`，支援樣態表 `JPM = ["ki_periodic"]`）。

探勘用的參考條件表是作業人員提供的公司原始待建檔格式（`data/orders/核對表格式..xlsx`，工作表 `ELN待建檔_測試`，5 列 JPM，與 JP1–JP5 全部對上；`ISIN Code`、`發行日`、`比價日_n` 為待回填的空白；沒有 `發行機構` 欄）。

實作時要登記：

- `config/reference_sheet.toml` `[issuer_values]`：`JPM = "JPM"`（`發行機構` 欄的寫法，2026-10-15 作業人員確認；待建檔表沒有這欄時以商品代號前 3 碼判定）。
- `config/reference_sheet.toml` `[underlyings] any_order_issuers`：加入 `JPM`（§3）。
- `src/fcn_checker/issuers.py`：JPM 範本（`jpm-zh-pd`、投資人須知 `jpm-zh-iis`）。

## 3. 允許值與 JPM 差異

| 欄 | 值 | 意義 |
|---|---|---|
| KO(Freq) | `D` | 每日觀察（`…起至最終評價日(含)止之每一個預定交易日`） |
| | `P` | 每期觀察（`於任一評價日(t)(t=k-N)`） |
| KO(memo) | `Y`／`N` | 記憶式／非記憶式（單一標的填 `N`，JP2） |
| KI(Freq) | `-` 或空白 | 無 KI（沒有觸碰價） |
| | `AM` | 到期觀察（`在最後評價日時…低於觸碰價`；JP3） |
| | `D` | 每日觀察（`觸碰事件評價日：自交易日(含)起至最後評價日(含)止`；JP2） |
| | `P` | 每期觀察：JPM 不支援樣態（`[unsupported_variants]`），辨識時攔下 |

- **標的不看順序（2026-10-15 確認，比照 Citi）**：JPM 說明書第 9 項的標的依**英文公司名稱字母順序**排列，參考條件表依交易時的順序填；4 份多標的樣本（JP1、JP3、JP4、JP5）表上順序都和說明書不同（代號與各價格都對得上）。JPM 加入 `[underlyings] any_order_issuers`：表上與說明書是同一組彭博代號（數量相同、沒有重複）就通過，各價格欄依代號找到說明書那一檔再比；代號集合不同、數量不同、有重複時照常判不一致。回填（VWAP 覆寫）寫到表上**相同代號**那一格；投資人須知標的代號（B11）同樣依代號配對。
- **期初定價 `VWAP`**（JP4）：說明書沒有寫期初定價方式，期初定價欄不核對；價格欄照共用規則（Issue #122）不比對，整份通過或人工放行後以說明書價格依代號覆寫。JP4 表上進場價空白、執行價與 KO 價四捨五入到 4 位後本來就等於說明書。
- **KI 價格欄**：表上 `UL_n_下限價` 對應說明書的 `觸碰價(i)`（JP2、JP3 成立）。
- **Non-Call = 天期的 P 型**（JP5）：只在最後評價日觀察 KO；表上 `KO(Freq)` = `P`、`Non-Call(月)` = 天期、KO(%) 與 KO 價照說明書（說明書有自動提前出場價，不必像 SG、Citi 補 100%）。比價日只填最後一格。
- 單位面額：USD 10,000、JPY 1,000,000、AUD 10,000（= 審查標準預設值）。
- `K(%)` 可為非整數（JP5）；表上執行價可能存 5 位以上小數，四捨五入到 4 位後與說明書相等。
- 標的價格幣別可和承作幣別不同（JP1：AUD 計價、日股；Issue #170）。

## 4. 比價日填法（共用規則見[參考條件表格式](reference-sheet.md) §4）

| 型態 | 填法 | 說明書日期 |
|---|---|---|
| `D` | `比價日_{Non-Call}` 與 `比價日_{天期}` | 開始：日期表第 Non-Call 期的 KO 起日——第 8 項寫 `於評價日(t)(t=k)` 時取 `評價日(t)` 欄（D-4，JP1），寫 `於觀察期間終止日(t)(t=k)` 時取 `觀察期間終止日(t)` 欄（D-3，JP2、JP4）；最後：最後評價日（= 日期表末列） |
| `P` | `比價日_{Non-Call}` 到 `比價日_{天期}` 每一期 | 日期表各期 `評價日(t)`；Non-Call = 天期時只填最後一格（JP5） |

探勘用的表比價日欄全部空白（待回填），無法用表驗證；填法依條文推得，實作後以回填結果請作業人員確認。

## 5. 不核對的欄位

`TS/IIS完成檢核`、`交易日期`、`Product`、`私銀註記`、`UF`、`分公司_n`、`分公司_n_承作金額`、`下一比價日`、`UL_n_Memo`、`期初定價`（JPM 說明書沒有出處）、無表頭欄（同其他上手）。

## 6. 探勘時發現的表上狀況（2026-10-15）

- JP1、JP3、JP4、JP5：表上 `UL_n` 順序和說明書不同（JPM 依代號配對，§3）。
- JP4（VWAP）：表上 `UL_n_進場價` 空白，執行價、KO 價存多位小數，四捨五入到 4 位後與說明書相符。
- JP2（單一標的）：表上 `UL_1_Memo` = `Y`、`KO(memo)` = `N`；`UL_n_Memo` 不核對，`KO(memo)` 與說明書（單一標的判 N）相符。
