## 1. 結構

探勘用的參考條件表是作業人員提供的公司原始待建檔格式（`data/orders/核對表格式..xlsx`，工作表 `ELN待建檔_測試`，5 列 CA，與 CA1–CA5 全部對上；`ISIN Code`、`發行日`、`比價日_n` 為待回填的空白；沒有 `發行機構` 欄）。

實作時登記：

- `config/reference_sheet.toml` `[issuer_values]`：`CA = "CA"`（`發行機構` 欄的寫法，2026-10-15 確認；待建檔表沒有這欄時以商品代號前 3 碼判定）。

## 2. 欄位對照

| Excel 欄 | 標準欄位 | 說明書來源（見[範本規格](../templates/ca-zh-product-description.md)） |
|---|---|---|
| TDCC Code | `product_code` | 封面 `● TDCC 商品代號：`（全文唯一出處） |

| 交易日 | `trade_date` | 第一章第 13 項 `(2) 期初訂價日：`（**說明書沒有「交易日」標籤**，2026-10-15 確認以期初訂價日核對） |
| 發行日／到期日 | `issue_date`／`maturity_date` | 第 13 項 `(3) 發行日：`／`(5) 到期日：`（發行日表上空白時回填） |

| KO(%) | `ko_pct` | 第 9 項價格表表頭 `自動提前出場價 (期初訂價之Y% )`（說明書沒有文字定義；情境價格表交叉驗證） |
| KO(Freq) | `ko_observation` | 第 9 項 `(b)`：觀察日表 = P、`自第k 個配息期結束日…每一個預定交易日` = D（範本規格 §4.1） |
| KO(memo) | `ko_memory` | 第 9 項 `(b)` `自動提前出場事件：` 兩句（範本規格 §4.2） |
| K(%) | `strike_pct` | 價格表表頭 `執行價 (期初訂價之X% )` |

## 3. 允許值與 CA 差異

| 欄 | 值 | 意義 |
|---|---|---|
| KO(Freq) | `D` | 每日觀察（`自第k 個配息期結束日 (含)至期末訂價日(含)的每一個預定交易日`；CA3–CA5） |
| | `P` | 每期觀察（第 9 項 `(b)` 自動提前出場觀察日表；CA1、CA2） |
| KO(memo) | `Y`／`N` | 記憶式（「或任何先前的…觀察日」＋「無須於同一…觀察日」）／非記憶式；多標的又沒有記憶式句型 → 轉人工覆核 |
| KI(Freq) | `-` 或空白 | 無 KI（CA1、CA2、CA5） |
| | `AM` | 到期觀察（`界限事件：若於期末訂價日…`；CA4） |
| | `D` | 每日觀察（`界限事件觀察期間：從期初訂價日(含)至期末訂價日(含)`；CA3） |
| | `P` | 不支援（`CA = ["ki_periodic"]`） |
| 期初定價 | `開盤價`／`收盤價`／`VWAP`／空白 | 說明書沒寫，不和說明書比、只檢查是允許值；`VWAP` 時價格欄照共用規則（Issue #122、#246）不比對、通過後覆寫（CA2） |

- **標的順序**：第 10 項、價格表與表上順序相同（5 份成立），照共用規則依順序比對，不加 `any_order_issuers`。
- **KI 價格欄**：表上 `UL_n_下限價` 對應說明書的 `下限價`（KI 樣本都成立）。
- **`UL_n_Memo` 不核對**（2026-10-15 確認）：說明書是整檔判斷記憶式。
- 單位面額：USD 10,000、EUR 10,000、JPY 1,000,000（= 審查標準預設值）。
- 表上執行價、下限價、KO 價可能存未四捨五入或浮點誤差的值，四捨五入到 4 位後與說明書相等（共用規則）。
- 標的價格幣別可和承作幣別不同（CA1：USD 計價含港股；CA4：EUR 計價、美股；Issue #170）。

## 4. 比價日填法（共用規則見[參考條件表格式](reference-sheet.md) §4）

| 型態 | 填法 | 說明書日期 |
|---|---|---|
| `D` | `比價日_{Non-Call}` 與 `比價日_{天期}` | 開始：配息表第 Non-Call 期 `配息期結束日`（= `自第k 個配息期結束日 (含)` 那一天）；最後：期末訂價日（= 配息表末列結束日） |
| `P` | 從 `比價日_{Non-Call}` 填到 `比價日_{天期}` | 第 9 項觀察日表每列的 `自動提前出場觀察日`；期別 = 同列 `自動提前出場日` 在配息日表的期別（**觀察日表的 `i` 不是期別**，CA2 只有 1 列 `i = 1`、對應第 12 期）。觀察日表列數須 = 天期 − Non-Call + 1，否則轉人工覆核 |
| Non-Call = 天期 | 只填 `比價日_{天期}` | 期末訂價日（CA2） |

探勘用的表比價日欄全部空白（待回填），無法用表驗證；填法依條文推得，實作後以回填結果請作業人員確認。
