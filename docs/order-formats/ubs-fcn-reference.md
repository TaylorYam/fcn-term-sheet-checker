## 2. 欄位對照

## 3. 允許值與 UBS 差異

| 欄 | 值 | 意義 |
|---|---|---|
| KO(Freq) | `D` | 每日觀察（`每日觀察，為自第k 個配息觀察期間結束日（包含）至期末訂價日…的任一預定交易日`；UB2、UB4、UB6） |
| | `P` | 每期觀察（`為自第k 個配息觀察的每個配息觀察日`；UB3、UB5） |
| KO(memo) | `Y`／`N` | 記憶式（「即使各股票在不同提前出場觀察日成為鎖定股票…」）／非記憶式 |
| KI(Freq) | `-` 或空白 | 無 KI（UB3–UB5） |
| | `D` | 每日觀察（`若在期初訂價日（含）至期末訂價日（含）間的任一預定交易日…`；UB2） |
| | `P` | 每期觀察（`若在任一配息觀察日…`；只有舊版 UB1，新版待樣本驗證） |
| | `AM` | 到期觀察（`若在期末訂價日…`；UB6） |
| 期初定價 | `開盤價`／`收盤價`／空白 | 說明書沒寫，不和說明書比、只檢查是允許值；`VWAP` 是 UBS 不支援樣態（辨識時攔下） |

- **標的順序**：九、價格表與表上順序相同（6 份成立），照共用規則依順序比對，不加 `any_order_issuers`。
- **KI 價格欄**：表上 `UL_n_下限價` 對應說明書的 `下限價`（KI 樣本都成立）。
- **`UL_n_Memo` 不核對**（2026-10-15 確認）：說明書是整檔判斷記憶式（UB3 非記憶式卻有一檔 `Y`）。
- 單位面額：USD 10,000、AUD 10,000、JPY 1,000,000（= 審查標準預設值）。
- 標的價格幣別可和承作幣別不同（UB3：AUD 計價日股；UB6：JPY 計價美股；Issue #170）。

## 4. 比價日填法（共用規則見[參考條件表格式](reference-sheet.md) §4）

| 型態 | 填法 | 說明書日期 |
|---|---|---|
| `D` | `比價日_{Non-Call}` 與 `比價日_{天期}` | 開始：配息表第 Non-Call 期 `配息觀察期間結束日`（= `自第k 個配息觀察期間結束日（包含）` 那一天）；最後：期末訂價日（= 配息表末列結束日） |
| `P` | 從 `比價日_{Non-Call}` 填到 `比價日_{天期}` | 配息表第 Non-Call 期起每列的 `配息觀察日`（新版含最後一期 = 期末訂價日） |

探勘用的表比價日欄全部空白（待回填），無法用表驗證；填法依條文推得，實作後以回填結果請作業人員確認。

## 5. 不核對的欄位

`TS/IIS完成檢核`、`交易日期`、`Product`、`私銀註記`、`UF`、`分公司_n`、`分公司_n_承作金額`、`下一比價日`、`UL_n_Memo`、無表頭欄（同其他上手）。`期初定價` 因說明書沒寫，只檢查是允許值、不和說明書比（§3）。
