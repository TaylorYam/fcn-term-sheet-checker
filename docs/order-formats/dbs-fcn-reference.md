## 1. 結構

與其他上手相同（版面見[參考條件表格式](reference-sheet.md) §1，每列一檔）。商品代號前 3 碼為 `078`（`config/issuer_prefixes.toml` 已登記 `DBS`；支援樣態表 `DBS = ["vwap", "ko_daily", "ko_periodic_memory", "ko_periodic", "ki_daily", "ki_periodic", "non_call_equals_tenor"]`：只支援 KO 每日觀察＋記憶式、KI 到期觀察或無 KI、非 VWAP、Non-Call < 天期）。

探勘用的參考條件表是作業人員提供的公司原始待建檔格式（`data/orders/核對表格式..xlsx`，工作表 `ELN待建檔_測試`，4 列 DBS，與 DB1–DB4 全部對上；`ISIN Code`、`發行日`、`比價日_n` 為待回填的空白；沒有 `發行機構` 欄）。

實作時登記：

- `config/reference_sheet.toml` `[issuer_values]`：`DBS = "DBS"`（`發行機構` 欄的寫法，2026-10-15 確認；待建檔表沒有這欄時以商品代號前 3 碼判定）。
- `src/fcn_checker/issuers.py`：DBS 範本（`dbs-zh-pd`、投資人須知 `dbs-zh-iis`）。
- **不加** `[underlyings] any_order_issuers`：說明書標的順序和表上相同（§3）。

## 2. 欄位對照

| Excel 欄 | 標準欄位 | 說明書來源（見[範本規格](../templates/dbs-zh-product-description.md)） |
|---|---|---|
| TDCC Code | `product_code` | 封面 `商品代號：`（`受託或銷售機構商品代號：` 交叉驗證） |
| ISIN Code | `isin` | 封面 `國際證券編碼ISIN：`（全文唯一出處；表上空白時回填） |
| 單位面額 | `denomination` | 商品基本資料 `商品面額：每單位{幣別}{面額}` |
| 計價幣別（承作幣別） | `currency` | 封面 `計價幣別：美元(USD)`（`美元`→USD、`澳幣`→AUD、`日圓`→JPY；對照表 `[currency]`）；商品基本資料 `計價幣別：` 交叉驗證 |
| 交易日 | `trade_date` | 商品年期格 `交易日：` |
| 發行日／到期日 | `issue_date`／`maturity_date` | 商品年期格 `發行日：`／`到期日：`（長段落第一個日期；發行日表上空白時回填） |
| 最終比價日 | `final_valuation_date` | 商品年期格 `定價日：`（長段落第一個日期；= 表A 末列觀察期間結束日） |
| KO(%) | `ko_pct` | 表1 表頭 `自動提前出場價格 (期初價格的Y%)`（說明書沒有文字定義；情境價格表交叉驗證） |
| KO(Freq) | `ko_observation` | `觀察日：…每一個規劃交易日`＋`自動提前出場決定日:…每一個觀察日` = D（範本規格 §4.1） |
| KO(memo) | `ko_memory` | 強制贖回 `記憶事件：`＋`若所有連結標的皆被視為記憶標的` = Y（範本規格 §4.2） |
| K(%) | `strike_pct` | 表1 表頭 `執行價格 (期初價格的X%)` |
| KI(%) | `ki_pct` | 表1 表頭 `下限觸發價格 (期初價格的Z%)`；無 KI 時 Excel 為空白或 `-` |
| KI(Freq) | `ki_type` | 到期贖回 `下限觸發事件：若任一連結標的於定價日…` = AM；沒有下限觸發 = 無（範本規格 §4.4） |
| Coupon p.a. (%) | `coupon_pa_pct` | 配息資料 `最大利率值：…為a%（即y%/12）` 的 y（a = y ÷ 12 無條件進位 4 位，說明書內部規則） |
| 天期(月) | `tenor_months` | 商品年期格 `商品年期： N個月。` |
| Non-Call(月) | `first_callable_period` | 強制贖回 `自動提前出場決定日: 從第k個觀察期間結束日` 的 k（阿拉伯數字；= 配息 `第1~k個觀察期間` 的 k） |
| 比價日_1～12 | `autocall_date_n` | 見 §4（表上空白時回填） |
| 期初定價 | `initial_pricing` | **說明書沒寫**，交 `absent`：只檢查表上是允許值，不和說明書比（2026-10-15 確認）；`VWAP` 是 DBS 不支援樣態 |
| UL_n | `underlying_n` | 商品基本資料連結標的資產表 `彭博代碼` 欄（`ABC UW`，本來就沒有 ` Equity`）；**照順序比對** |
| UL_n_進場價／執行價／下限價／KO價 | `underlying_n_initial_price`／`_strike_price`／`_ki_price`／`_ko_price` | 表1 期初價格／執行價格／**下限觸發價格**／自動提前出場價格（表1 有彭博代碼，第 n 列代碼 = 標的表第 n 列） |

## 3. 允許值與 DBS 差異

| 欄 | 值 | 意義 |
|---|---|---|
| KO(Freq) | `D` | 每日觀察（`從第k個觀察期間結束日（包含）開始至預定規劃定價日（包含）為止的期間內的每一個觀察日`；DB1–DB4） |
| | `P` | 不支援（`ko_periodic`、`ko_periodic_memory`） |
| KO(memo) | `Y` | 記憶式（「記憶事件」＋「所有連結標的皆被視為記憶標的」） |
| | `N` | 不支援（`ko_daily` = KO 每日非記憶式） |
| KI(Freq) | `-` 或空白 | 無 KI（DB1、DB3） |
| | `AM` | 到期觀察（`下限觸發事件：若任一連結標的於定價日…`；DB2、DB4） |
| | `D`／`P` | 不支援（`ki_daily`、`ki_periodic`） |
| 期初定價 | `開盤價`／`收盤價`／空白 | 說明書沒寫，不和說明書比、只檢查是允許值（4 份表上都是收盤價） |
| | `VWAP` | 不支援（`vwap`） |
| Non-Call(月) | < 天期 | `= 天期` 不支援（`non_call_equals_tenor`） |

- **標的順序**：連結標的資產表、表1 與表上順序相同（4 份成立），照共用規則依順序比對，不加 `any_order_issuers`。
- **KI 價格欄**：表上 `UL_n_下限價` 對應說明書的 `下限觸發價格`（KI 樣本都成立）。
- **`UL_n_Memo` 不核對**（2026-10-15 確認）：說明書是整檔判斷記憶式。
- 單位面額：USD 10,000、AUD 10,000、JPY 1,000,000（= 審查標準預設值）。
- 表上執行價、下限價可能存未四捨五入的值，四捨五入到 4 位後與說明書相等（共用規則）。
- 標的價格幣別可和承作幣別不同（DB1：AUD 計價、DB4：JPY 計價，都連美股，名稱寫 `Quanto`；Issue #170）。

## 4. 比價日填法（共用規則見[參考條件表格式](reference-sheet.md) §4）

| 型態 | 填法 | 說明書日期 |
|---|---|---|
| `D` | `比價日_{Non-Call}` 與 `比價日_{天期}` | 開始：表A 第 Non-Call 期 `觀察期間結束日`（= `從第k個觀察期間結束日（包含）` 那一天）；最後：定價日（= 表A 末列觀察期間結束日） |

同 BBVA、CA 的 KO 每日型（2026-10-15 確認）。探勘用的表比價日欄全部空白（待回填），無法用表驗證；填法依條文推得，實作後以回填結果請作業人員確認。

## 5. 不核對的欄位

`TS/IIS完成檢核`、`交易日期`、`Product`、`私銀註記`、`UF`、`分公司_n`、`分公司_n_承作金額`、`下一比價日`、`UL_n_Memo`、無表頭欄（同其他上手）。`期初定價` 因說明書沒寫，只檢查是允許值、不和說明書比（§3）。

## 6. 探勘時發現的表上狀況（2026-10-15）

- DB1、DB3：表上執行價存多位小數，四捨五入到 4 位後與說明書相符。
- `UL_n_Memo`：DB1、DB3 有值（Y／N 混合），DB2、DB4 是 `-`。不核對。
- 其餘欄位（代號、幣別、面額、各日期、天期、K／KO／KI % 與型態、KO 觀察方式、記憶式、Non-Call、年利率、標的代號與順序、各價格）4 份全部相符。
