## 3. 允許值與 Citi 差異

| 欄 | 值 | 意義 |
|---|---|---|
| KO(Freq) | `D` | 每日觀察（§12(9) `每一個預定交易日`） |
| | `P` | 每期觀察（§13 `於觀察日，所有連結標的…`）；**無自動提前出場的商品也填 `P`**（CT5、CT6） |
| KO(memo) | `Y`／`N` | 記憶式／非記憶式 |
| KI(Freq) | `-` 或空白 | 無 KI |
| | `AM` | 到期觀察（`在期末評價日`） |
| | `D` | 每日觀察（`每一個預定交易日`）；CT7 |
| | `P` | 每期觀察（`在任t 個觀察日`）；只有舊文件 CT1 |
| 期初定價 | `收盤價`／`開盤價`／`VWAP` | 與 §9 表頭相同才通過；表頭其他寫法轉人工覆核 |

- **標的不看順序（Citi 專屬，2026-10-14 確認）**：CT2–CT6 共 5 份表上 `UL_n` 的排序和說明書 §9 不同（代號與各價格都對得上）。Citi 改成**依彭博代號配對**：表上與說明書是同一組代號（數量相同、沒有重複）就通過，各價格欄依代號找到說明書那一檔再比；代號集合不同、數量不同、有重複時照常判不一致。其他上手維持「依順序逐字相等」。實作為上手可選的行為（例：`Issuer` 的旗標），不在共用規則寫死 Citi 判斷。
- **回填**：VWAP 以說明書價格覆寫進場價等欄時，寫到表上**相同代號**那一格（CT4 即順序不同的 VWAP 商品），不能依說明書順序寫。
- **無自動提前出場**（CT5、CT6；同 SG）：說明書沒有自動提前出場界限與觀察日；表上 `KO(Freq)` = `P`、`KO(%)` = `100`、`Non-Call(月)` = 天期、`UL_n_KO價` = 進場價，比價日只填最後一格。Non-Call 等於天期時機制仍在、只是不會觸發，工具把 KO 視為期初股價的 100%，表上 `KO(%)` 與 `UL_n_KO價` 照常比對。
- **期初定價 `VWAP`**（CT4）：表頭寫明 VWAP，期初定價欄核對；價格欄照共用規則（Issue #122）不比對，整份通過或人工放行後以說明書價格覆寫（依代號）。CT4 表上進場價空白、執行價與 KO 價四捨五入到 4 位後本來就等於說明書。
- 單位面額：USD 10,000、JPY 1,000,000、CNH 100,000（= 審查標準預設值）。
- 承作幣別 `CNH`：封面寫 `境外人民幣`，英文名稱寫 `CNH`。CT5 為 quanto（美股標的），標的價格幣別 ≠ 承作幣別允許（Issue #170）。
- `K(%)` 可為非整數（CT5、CT6）；表上執行價可能存 5 位以上小數，四捨五入到 4 位後與說明書相等。

## 4. 比價日填法（共用規則見[參考條件表格式](reference-sheet.md) §4）

| 型態 | 填法 | 說明書日期 |
|---|---|---|
| `D` | `比價日_{Non-Call}` 與 `比價日_{天期}` | 開始：日期表第 Non-Call 期**配息觀察期間結束日**（= §12(9) 觀察起日；同 MS「該期配息週期終止日」）；最後：日期表末列結束日（= 期末評價日） |
| `P` | `比價日_{Non-Call}` 到 `比價日_{天期}` 每一期 | 日期表各期觀察日 |
| 無自動提前出場 | 只有 `比價日_{天期}` | §12(5) 期末評價日（日期表只有配息日） |

探勘用的表比價日欄全部空白（待回填），無法用表驗證；填法依條文推得，實作後以回填結果請作業人員確認。
