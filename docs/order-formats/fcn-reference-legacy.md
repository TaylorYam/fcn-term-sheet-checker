# 下單資料格式（已停用）：FCN參考條件.xlsx

> **2026-10-01 起 BARC 停用。** 下單資料改用各家上手的原始詢價格式（BARC 見 [barc-inquiry.md](barc-inquiry.md)）。本文件保留當時的欄位結構與比對規則，供參考與回溯。
>
> **例外：HSBC 暫用。** HSBC 原始詢價表尚未取得，暫用新版整理表 `FCN參考條件_1001.xlsx` 的 `樣本清單` 工作表（欄位結構同本文件），見 [hsbc-fcn-reference.md](hsbc-fcn-reference.md)。

這份 Excel 是使用者整理過的已確認條件，涵蓋多家上手、每列一檔商品。探勘階段曾用它與 8 份 BARC 說明書比對（342 項，無不一致）。

## 1. 結構

| 項目 | 內容 |
|---|---|
| 工作表 | `工作表1`（目前只有一張） |
| 表頭 | 第 3 列；第 1–2 列空白 |
| 資料 | 第 4 列起，每列一檔商品 |
| 配對鍵 | `TDCC Code` = PDF p1 商品代號（12 位，文字格式） |

## 2. 不核對的欄位

`庫存狀態`、`當日比價`、`私銀註記`、`UF`、`UL_n_Memo`、`BV` 欄。這些是存續或內部資訊，TS 裡沒有對應資料。`UL_n_Memo` 看起來是存續期間各標的的記憶狀態，`BV=1` 與「已於…KO」同列出現。

## 3. 欄位對照與規則

| Excel 欄 | PDF 來源（見範本規格） | 規則 |
|---|---|---|
| TDCC Code | p1 商品代號 | 字串相等 |
| ISIN Code | p1 ISIN | 字串相等 |
| 發行機構 | p1 發行機構含 `Barclays Bank PLC` | 對應為 `Barclays` |
| 單位面額 | §6 面額 | 整數相等 |
| 承作幣別 | p1 計價幣別 | `美元→USD`、`日幣→JPY`、`人民幣→CNH`；不在對照表內的幣別轉人工覆核 |
| 交易日、發行日、最終比價日、到期日 | §13(2)(3)(4)(5) | 日期相等 |
| 比價日_1～12 | §13 提前出場觀察日 | 見 §4 |
| KO(%) | §15 觸發百分比 | 數值相等 |
| KO(Freq) | §13 表頭型態 | 期間觀察 `D`、定日 `P` |
| KO(memo) | 商品名稱含 `記憶式` | `Y`／`N` |
| K(%) | §15 執行百分比 | 數值相等 |
| KI(%) | §15 觸及生效百分比 | 數值相等；PDF 無定義時 Excel 必須是 `-` |
| KI(Freq) | §15 是否有 `觸及生效評價日` | 有 → `D`；只有觸及生效價格 → `AM`；無 KI → `-` |
| Coupon p.a. (%) | §14 年利率 | 數值相等 |
| 天期(月) | §13(1) 年期 | 整數相等 |
| Non-Call(月) | §13 表格推導（[範本規格](../templates/barc-zh-product-description.md) §4.3） | 整數相等 |
| UL_n | §10 彭博代號去掉 ` Equity` | 依表格順序逐一相等；兩邊標的數量也要相同 |
| UL_n_進場價／執行價／下限價／KO價 | §15 價格表 | 價格四捨五入到 4 位後比對 |

## 4. 比價日填法

- **P（定日觀察）**：每個可以提前出場的期別都要填，等於該期評價日；不可提前出場的期別填 `-`。
- **D（期間觀察）**：只填「第一個可以提前出場的期別」和「最後一期」，等於該期的 `期末日`；其他期別填 `-`。
- 該填的位置沒填，或不該填的位置有值，都算不一致。
