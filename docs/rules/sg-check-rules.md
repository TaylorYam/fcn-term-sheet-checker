## 1. 範圍

- 6 份樣本：新版面 4 份（2025-10 起）、舊版面 2 份（SG5 為 2023 舊範本、SG6 為 2026 年文件但沿用舊版面）；兩種版面同一範本處理（範本規格 §1.1、§8）。舊範本的舊警語、舊負責人判不通過是預期結果（2026-10-13 確認）。
- 本文件只寫說明書（TS）。SG 投資人須知（IIS，4 頁）見 [範本規格](../templates/sg-zh-iis.md) 與[投資人須知核對規則](iis-check-rules.md) §3 SG 欄（Issue #213，已實作）；兩份都通過或人工放行才打 `TS`／`IIS` 的 `V` 並回填（ADR 0007）。
- 核對範圍依開發者螢光清單（主樣本 66 項、型態段落 31 項）逐項決定；作業人員決定跳過 §3 雙方螢光取交集（2026-10-13）。

### 3.3 年利率與配息率

| 檢查 | 規則 |
|---|---|
| 年利率 | §8 `(年率 Y%)` = 參考條件表 `Coupon p.a. (%)`（共用 `field.coupon_pa_pct`）；§15 獲利情境（有自動提前出場：情境一、二；無：情境一）每處 `平均年化報酬率：Y%` = 年利率（2 位寫法，比對數值） |
| 配息率 | §8 `配息率 ＝X%`、§15 假設 `配息率 = X %`、§15 每個情境算式 `×X%`：每處都 = 年利率 ÷ 12，四捨五入（half-up）到 **4 位**（6 份成立，JPY 也 4 位；與 BNP 的「依顯示位數」不同，SG 固定 4 位） |

這些規則讀參考條件表的年利率（ADR 0005 例外，同 BARC／MS／BNP）。

### 3.4 價格

- 共用 `derive.prices`：§8 標的表各標的執行價／自動提前出場價／下限價 = 期初價格 × 該百分比，half-up 到 4 位；列數 = 標的數；有無「下限價」欄與 KI 型態一致、有無「自動提前出場價」欄與有無自動提前出場一致（6 份成立；K % 非整數的 SG6 也成立）。
- 百分比各只寫一次（§8 三行），不必檢查「每檔相同」。
- 疑似分割／除權息調整：共用規則（[BNP 核對規則](bnp-check-rules.md) §3.4）：同一檔標的各價格與表上差同一比例 → 該檔價格欄轉人工覆核，表上值不改（SG5 `UL_2` 實證）。
- §15 重印表逐格 = §8（期初、自動提前出場、下限、執行價與表頭的三個 %）；較差／最差情境 `/ N` 的 N = §8 表現最差標的（情境假設的那一檔 `(k=n)`；單一標的即該檔）的執行價，去尾零後數值相等。

### 3.7 情境分析（§15(3)，SG 專屬）

2026-10-13 確認納入情境算式（範圍比照 BNP），算法同 MS：總配息 = 已進位的每期配息 × 期數。

| 檢查 | 規則 |
|---|---|
| 假設 | `總投資金額 = U單位面額 = N 幣別`：N = U × 面額（U 從說明書讀）；`天期：n個月` = 天期；`配息率 = X %` = §3.3 |
| 每期配息 | 每個情境 `第a~b個配息金額 = U單位面額x{面額}x X%` 之後 `= N x X%` 的下一行 `= A 幣別`：A = N × 配息率，half-up 到 2 位（JPY 也 2 位） |
| 期別 | 情境一 a~b = 1～Non-Call（Non-Call = 1 時寫 `第1個`）；其餘情境 1～天期；無自動提前出場時所有情境 1～天期 |
| 累積總配息金額 | `= A × 期數`，或 `= 總投資金額 × 配息率 × 期數` 再四捨五入到 2 位，符合任一種即通過（2026-10-15，#244，同 BNP） |
| 贖回金額 | `自動提前出場贖回金額`／`到期贖回金額 = U單位面額x{面額}x100%` → `= N x100%` → `= N 幣別` = 總投資金額 |
| 獲利情境總報酬率 | `= (N+累積 / N)-1` → `= r%(平均年化報酬率：Y%)`：r = 累積 ÷ N（4 位）；Y = 年利率（2 位） |
| 較差／最差情境 | 每期配息、累積同上；`數額計算 = 每單位面額 / …執行價` → `= 面額 / 執行價` → `= s`（無條件進入 4 位）；`應實際交付數 = 數額向下調整至最接近的整數位 = S單位`；`加上現金交割 = 假設收盤價 x 畸零數 = R`（無條件進入 2 位）；`總投資金額 = U單位面額，因此…連結標的 U×S單位加上現金 U×R`；括號內 `總報酬率 = {[N x(收盤價 / 執行價) + 累積]/ N} -1 = r%（平均年化報酬率：y%）`：r 以文件的假設收盤價驗算（2 位），y = 未四捨五入的 r × 12 ÷ 天期（依文件位數四捨五入；6 份樣本 11 個情境皆如此）。SG6 型（quanto）另有 `最終匯率定價 = …` 行與匯率換算：匯率是試算值，用文件的匯率驗算 |

情境標題與期別寫法未知、或算式找不到時轉人工覆核，不跳過後宣稱通過。

## 4. 判定原則

沿用 BARC：必核欄位抓不到、抓到多個不同值、或寫法不在範本規格內，一律轉人工覆核；「不適用」（例：無 KI、無自動提前出場）必須由說明書明確判斷（§8 沒有 `下限價：` 行且到期贖回為以執行價判的兩款；§8 沒有 `自動提前出場事件：` 段且標的表沒有自動提前出場價欄且名稱沒有自動提前出場字樣）。
