### 3.1 範圍

**只要是變動參數（不是每份 TS 都一樣的）就要核對。** 有 Excel 欄位的直接比；Excel 沒有的，用推導關係或 PDF 內部交叉驗證。

### 3.3 比價日填法（固定規則）

- **P（定日觀察）**：每個可以提前出場的期別都要填，等於該期評價日；不可提前出場的期別填 `-`。
- **D（期間觀察）**：只填「第一個可以提前出場的期別」和「最後一期」，等於該期的 `期末日`；其他期別填 `-`。
- 該填的位置沒填，或不該填的位置有值，都算不一致。

### 3.4 數值與小數位

- Excel 數字可能有二進位浮點尾數（例：`x.xx64999999994`），先四捨五入到 9 位小數清掉尾數。
- 價格：再四捨五入（half-up）到 4 位小數，跟 PDF 相同就算一致。Excel 可能存未四捨五入的計算值（例：6 位小數），也按這個規則處理。
- 百分比：比到 PDF 顯示的位數（2 位）。

### 3.5 月配息率（2026-10-01 確認）

- **總配息率是正確值**：總配息率 = Excel 年利率 × 天期 ÷ 12。
- 推算月配息率 = 總配息率 ÷ 商品期數（期數 = PDF 配息表列數，目前每月一期，等於天期）。
- 推算值與 PDF 月配息率**差距 ≤ 0.0001 視為一致**；超過才判不一致。

背景：用上式四捨五入到 4 位，14 份樣本中有 4 份（S06、S08、S10、S12）比 PDF 少 0.0001（例：年利率 10.00% → 推算 0.8333%，PDF 0.8334%）；沒有任何單一進位方式能讓 14 份全部吻合，因此採用容差。

PDF 內部另外要求：月配息率在 §9(1)、§14、§15(2)、§17(1) 都相同；年利率在 §9(1)、§14、§17(1) 都相同。

### 3.6 標的（2026-10-01 確認）

**目前只核對彭博（BB）英文代號**：

- PDF §10 彭博代號（去掉 ` Equity`）= Excel `UL_n`，依順序逐一相等，標的數量也要相同。
- 代號包含交易所尾碼，**逐字比對**。尾碼代表交易所，會影響報價，例如 `XXX UW` 與 `XXX UQ` 視為**不同標的**，不可互相對應或自動轉換。

中文名稱與交易所欄位暫不核對（標的對照表擱置，見 §6.2）。PDF 內部仍檢查 §10、§15 的標的名稱前後一致，但只作參考、不影響判定。

#### 擱置中的後續規則（供日後參考）

上手以彭博代號為準，再依代號對應的中文名稱填寫說明書。若日後恢復名稱核對，預定做法：

1. 以「上手＋彭博代號」為主鍵查標的對照表，取得中文名稱與交易所；
2. PDF 中文名稱與交易所 = 對照表；代號不在表內 → 轉人工覆核，不從 PDF 反推。

已知注意事項：
- 不同上手對同一標的的中文寫法不同（例：全名＋ADR／簡稱＋ADR／簡稱），對照表必須分上手；
- 同一家公司不同股票類別可能共用中文名稱，主鍵只能是代號；
- 「中文名稱」可能是英文公司名，照原字串比對；PDF 中英文名稱換行時要補回空白。

## 4. 判定原則

- 任何必核欄位抓不到、抓到多個不同值、或型態不屬於範本規格列出的寫法，都轉人工覆核，不猜值、不算通過。
- 「雙方皆無」（例：無 KI 商品的 KI 欄位）必須由 PDF 明確判斷為不適用，才算通過。
- 報告保留每一項的 Excel 值、PDF 值與 PDF 出處（頁碼、座標）。
