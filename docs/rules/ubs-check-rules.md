## 2. 不核對的項目（2026-10-15 確認）

- 發行機構註冊地、主要營業地點、商品註冊地、公會審查；計算代理機構、報價機構、保管機構、結算機構、交付機構、準據法、律師意見、國外相當交易條件。

- 警語 2～10 的全文（只保留全文禁用語檢查）。
- 十五情境的配息金額、總配息、股數、剩餘金額、結算收益、平均年化報酬率、期末價格；情境一～四的條件句與提前出場期別、情境三寫出的轉換價與假設收盤價、D 型假設的交易日數（§3.7；重複寫出的面額、配息率、幣別、配息觀察次數與提前出場觀察日另有核對，#320）。
- 十三「配息前淨值、配息率」的例子（示意數字，不是本商品配息率）；十四、十六～二十四只有參照、稅法 % 與日期（#320 探勘）。

- 一般交易事項：申購結束受理日、受理投資人提前贖回開始日與後續日期、截止時間（只有文字）；三、五、六、七（發行不成立，沒有門檻）、九～十五、十七；流程圖文字。

## 3. 核對規則

### 3.1 參考條件表欄位（共用 `rules/reference.py`）

語意與 rule_id 同 BARC。UBS parser 只負責交出標準欄位；來源見 [UBS 下單資料格式](../order-formats/ubs-fcn-reference.md) §2。

| 標準欄位 | 規則（rule_id） | UBS 差異 |
|---|---|---|
| 商品代號、ISIN、幣別、面額、各日期、天期、百分比、KO／KI 型態、Non-Call、比價日 | 共用（`field.*`、`backfill.*`） | 代號取第 1 頁一、`TDCC 商品代號為`；ISIN 只有商品基本資料二十五 1 處；幣別只寫中文；**交易日取十二 `交易日/期初訂價日`**；K／KI／KO % 取八價格表表頭；KI 欄位來自「下限價」；KO 有 D、P 兩型（範本規格 §4.1）；KI 有 D、P、AM、無（範本規格 §4.4） |
| 年利率 `coupon_pa_pct` | 共用 `field.coupon_pa_pct` | 八 `固定配息率：x%（年化配息率為y%）` 的 y（說明書有年利率，不需要 `reference_fields`） |
| 標的 `underlyings`、各標的價格 | 共用 `field.underlyings`、價格規則 | 代號取九；價格表只有中文名稱，依名稱（= 九同列名稱）對到代號；照順序比對（6 份順序相同，不加 `any_order_issuers`） |

### 3.3 配息率（2026-10-15 確認）

| 檢查 | 規則 |
|---|---|
| 年利率 | 八 `年化配息率為y%`（P 型 `年化配息率y%`）的 y = 參考條件表 `Coupon p.a. (%)`（共用 `field.coupon_pa_pct`） |
| 月配息率 | 八 `固定配息率：x%` 的 x = y ÷ 12 四捨五入（half-up）到 4 位（6 份成立） |
| 其他出處 | D 型 `變動配息率：x%X（nt/Nt）（年化配息率為y%）`（UB4 寫 `配息率：`）的 x、y = 固定配息率那一句，十五設定參數重複的那一句也是（#303）；十五情境 `固定配息率：x%`（有年化時 y）= 八；十五情境分析算式代入的配息率 `X x% X` 每一處 = 八的 x（#320，一筆結果帶出每一處） |
| 配息頻率 | 配息表列數 = 天期（每月一期）；不同判不一致（`doc.coupon_periods`） |
| D 型期別 | 配息表公式欄 `固定配息率` 的期數 = Non-Call、其後都是 `變動配息率`；`t 係為a 至b 的數字` 的 a = Non-Call + 1、b = 天期，八與十五設定參數兩處（#303）（§3.5） |
| `nt/Nt` | 不推算（只作型態佐證） |

### 3.4 價格與百分比

- 共用 `derive.prices`：八價格表各標的轉換價／下限價／提前出場價 = 期初價格 × 百分比，half-up 到 4 位後數值相等（6 份成立，含日股）；列數 = 九的標的數；有無下限價欄與 KI 型態一致。
- **表頭 % 是 K／KI／KO % 的主來源**：八表頭 = 參考條件表（共用 `field.*`）、= 十五情境價格表表頭（§3.7）；KO 條款寫出 `提前出場價（即期初價格的Y%）` 時（UB3）Y = 表頭。**欄序 K → KI → KO**，依表頭關鍵字順序決定，不可寫死。表頭讀不到 % → 轉人工覆核。
- 價格表每列名稱（刪除 U+F020、忽略空白後）= 九的標的表同列名稱；不同 → 該列對不到代號，轉人工覆核。
- 期初價格一律 4 位小數。
- 疑似分割／除權息調整：共用規則（[BNP 核對規則](bnp-check-rules.md) §3.4；樣本沒有這種情形）。

### 3.5 說明書內部交叉驗證（UBS 專屬）

| 檢查 | 規則 |
|---|---|
| 商品代號 | 第 1 頁一、`受託機構(/銷售機構)商品代號為` = `TDCC 商品代號為`（`doc.trustee_product_code`） |
| 名稱 | 第 1 頁中文名稱 = 商品基本資料一（忽略空白與句尾 `。`、括號統一；`瑞銀（定期觀察）`／`瑞銀（每日觀察）` 與不加括號的寫法視為相同，2026-10-15 確認） |
| 幣別 | 第 1 頁五 = 商品基本資料五（只寫中文，查 `[currency]`） |
| 發行分行 | 第 1 頁四、商品基本資料三、相關機構事業概況一、(一) 三處都寫 `倫敦分行`（`經由瑞士境外之倫敦分行`、`經由倫敦分行`、`透過其倫敦分行` 等價）；其他分行或讀不到 → 轉人工覆核（2026-10-15 確認只有倫敦分行） |
| 期數 | 配息表列數 = 天期 = 十五情境 `天期：N 個月` = 十五設定參數 `每月（共N個）`（#320） |
| KO 型態 | 八與十二 `提前出場觀察日：` 寫法相同；D 型 ⇔ 配息觀察期間表（開始日／結束日）；P 型 ⇔ 配息觀察日表（範本規格 §4.1、§5.2） |
| Non-Call | `提前出場觀察日` 的 k ≤ 配息表列數；D 型固定配息期數 = k、`t 係為a 至b`（八與十五設定參數）的 a = k + 1、b = 天期；十五寫出 `提前出場觀察日：…`（P 型設定參數、部分 D 型）時觀察方式與 k = 八（`doc.autocall_terms`，#320；沒有這句不核對） |
| 面額其他出處 | 八 `發行價格：N%，即X` 的 X = 八每單位面額 × N%（寫 `每單位面額之N%` 沒有金額時不核對）；一般交易事項四 `每單位面額`、五 `申購價金之計算：X幣別 X 申購單位數…` 的 X = 八每單位面額（`doc.denomination_mentions`，#303）；十五情境分析算式代入的每單位面額（`=X幣別X…`、`=（X幣別/…`、`-X幣別=`）每一處 = 八面額（#320，一筆結果帶出每一處） |
| 記憶式 | 「即使各股票在不同提前出場觀察日成為鎖定股票…仍被視為發生」與 `鎖定股票：` 定義都有 = Y；都沒有、且有非記憶式的提前出場事件句 = N（Issue #297）；只有其一、記憶式與非記憶式句同時出現或兩種都沒有 → 轉人工覆核（範本規格 §4.2） |
| KI | 八 `觸及下限事件` 定義句、到期日給付有無 `若觸及下限事件`、價格表有無下限價欄三者一致（範本規格 §4.4） |
| 名稱型態字樣 | 名稱樣板（§3.6）已依 KO 觀察方式、記憶式、KI 產生預期名稱，觀察方式不符（UB2、UB4）由 `standard.product_name` 判不一致 |
| 日期表 | 配息表列數 = 天期、期別連續、給付日遞增、末列給付日 = 到期日；P：末列觀察日 = 期末訂價日、觀察日 < 同列給付日；D：末列結束日 = 期末訂價日、開始日 ≤ 結束日 < 同列給付日 |
| 到期日 | 十二 `期末交割日/到期日` 的現金、證券交割兩個日期相同 |
| 情境價格表 | 十五情境價格表逐格（期初價格與各價格）= 八價格表、表頭 % = 八（§3.7）；結果的預期值／實際值帶出每一格、表頭 % 與設定參數（#320） |

### 3.6 固定警語、名稱（審查標準 UBS 設定）

**固定風險警語**（`risk.fixed_warning_by_issuer.ubs`，2026-10-15 確認視為正確）：UBS 版本 = 共用版（`risk.fixed_warning`）只差 3 處：

## 4. 判定原則

沿用 BARC：必核欄位抓不到、抓到多個不同值、或寫法不在範本規格內，一律轉人工覆核；「不適用」（例：無 KI）必須由說明書明確判斷（沒有 `觸及下限事件` 定義、到期日給付直接比轉換價、價格表沒有下限價欄）。
