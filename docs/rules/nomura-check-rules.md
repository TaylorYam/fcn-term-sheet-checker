- 文件側：[Nomura 範本規格](../templates/nomura-zh-product-description.md)；投資人須知見 [Nomura 投資人須知範本規格](../templates/nomura-zh-iis.md)與[投資人須知核對規則](iis-check-rules.md) §3 Nomura 欄
- 下單側：參考條件表，見[參考條件表格式](../order-formats/reference-sheet.md)與 [Nomura 下單資料格式](../order-formats/nomura-fcn-reference.md)
- 會隨時間改變的基準見[審查標準](review-standard.md) §2.11（設定檔 `config/review_standard.toml`）
- 狀態：核對範圍與規則已與作業人員確認（2026-10-15，Issue #239）；已實作（`parsers/nomura.py`、`rules/nomura.py`，投資人須知見[投資人須知核對規則](iis-check-rules.md)）
- 本文件只寫與 [BARC](barc-check-rules.md)、[HSBC](hsbc-check-rules.md)、[MS](ms-check-rules.md)、[BNP](bnp-check-rules.md)、[SG](sg-check-rules.md)、[Citi](citi-check-rules.md)、[JPM 核對規則](jpm-check-rules.md)不同或 Nomura 特有的部分；未提到的原則（判定原則、數值處理、期初價格本身不核對等）見[共用核對規則](shared-check-rules.md)

## 1. 範圍

- 8 份樣本（NR1–NR8），同一範本版本（NR1、NR2 為 2025 年文件，只有空白與審查日期不同）。
- 說明書（TS）與投資人須知（IIS）在同一張 Issue 處理；投資人須知規則見[投資人須知核對規則](iis-check-rules.md) §3 Nomura 欄。
- 核對範圍依開發者凍結清單（說明書 T01–T26、投資人須知 I01–I10）逐項決定；作業人員決定不畫螢光（2026-10-15）。

## 2. 不核對的項目（2026-10-15 確認）

- 沿用 BARC／HSBC／MS／BNP／SG／Citi／JPM：整理表存續或內部欄位、信用評等、發行機構方負責人、財報、匯率、到期贖回價值。
- 連結標的英文名稱、交易所、關連交易所（第 7、8、9 項；只核對彭博代碼與檔數）。
- 發行機構、總代理人、保證機構的**地址與電話**（三者名稱要核對，§3.6）；總代理人、計算代理機構、付款代理機構負責人。
- 固定警語(二)～(十二) 的全文（只保留全文禁用語檢查）。
- 第 14 項情境分析的情境三、四（假設價格、股數、剩餘金額、損失率）與情境二的算式（只核對設定參數、百分比表、情境一／二的年化報酬率，§3.7；2026-10-15 確認）。
- 參考條件表「期初定價」欄（說明書沒有寫期初定價方式；2026-10-15 確認，同 SG、JPM）。
- 封面 `發行機構註冊地`、第一章第 4、6、10、12、13、17–21 項、第 11 項 (5)、(7)、(9)–(13)、第二章 1.(2)–(8)、2.(2)–(9)、3.(2)(3)(5)(6)、4.、5.、第三章（6.(1) 固定警語以外）、第四章 3.、6.、9.–14.、16.、第五章全部。
- 開始／後續受理贖回日期（說明書只有文字；投資人須知須與說明書文字相同，見[投資人須知核對規則](iis-check-rules.md) D36）。
- 第 7 項配息金額的進位寫法、自動提前出場日與預定到期日的營業日所在地（紐約／東京／東京及雪梨）。
- 實物交割的最終匯率條款；準據法。
- 發行日 − 交易日、預定到期日 − 最終評價日的天數（只作參考；到期日和參考條件表比）。

## 3. 核對規則

### 3.1 參考條件表欄位（共用 `rules/reference.py`）

語意與 rule_id 同 BARC。Nomura parser 只負責交出標準欄位；來源見 [Nomura 下單資料格式](../order-formats/nomura-fcn-reference.md) §2。

| 標準欄位 | 規則（rule_id） | Nomura 差異 |
|---|---|---|
| 商品代號、ISIN、幣別、面額、各日期、天期、百分比、KO／KI 型態、Non-Call、比價日 | 共用（`field.*`、`backfill.*`） | K／KO／KI % 只在第 7 項標的表**表頭**；KI 欄位來自「下限觸發價」；到期日取第 11 項 (4) 預定到期日；Non-Call：D 型由 KO 起日對到日期表期別、P 型由日期表第一個非 `不適用` 決定日 |
| 年利率 `coupon_pa_pct` | 共用 `field.coupon_pa_pct` | **說明書沒有年利率**：由每期配息率 × 12 推得（§3.3）。parser 交出推得的年利率時須帶「推得」證據（每期配息率原文），或改由 Nomura 專屬規則讀參考條件表年利率比對（實作時擇一，見 §7） |
| 標的 `underlyings`、各標的價格 | 共用 `field.underlyings`、價格規則 | 依順序比對（8 份表上順序都和說明書相同）；彭博代碼去掉 ` Equity` |
| 期初定價 `initial_pricing` | 共用 `field.initial_pricing` | 說明書沒有出處 → 交 `absent`，不核對 |
| 最低金額 `min_amounts` | 共用 `field.min_amounts` | 第四章 4. 最低申購、最低加價申購、8. 最低贖回、增加贖回單位、第一章第 16 項(1) 最低提前贖回金額、增加贖回單位 = 單位面額 × 1（所有幣別；不需要 `min_amount_multiples.nomura`） |
| 金額旁的幣別 `currency_others` | 共用 `field.currency`（Issue #170） | 第 7 項表最低投資金額、面額；第 14 項面額；第 16 項(1) 兩處；第四章 4. 兩處、8. 兩處各一筆。標的表價格、情境算式金額不列入 |

### 3.3 配息率（2026-10-15 確認）

說明書只寫每期（每月）配息率，沒有年利率。

| 檢查 | 規則 |
|---|---|
| 年利率 | 第 7 項 `固定配息率：就每配息日而言，X%` 的 X × 12，四捨五入（half-up）到 2 位 = 參考條件表 `Coupon p.a. (%)`（8 份成立；X 本身也 = 年利率 ÷ 12 四捨五入到 4 位） |
| 配息頻率 | 日期表列數 = 天期（每月配息）才做上面的換算；列數 ≠ 天期 → 轉人工覆核（樣本都是每月） |
| 每期配息率其他出處 | 第 15 項(1)、第 14 項設定參數 `固定配息率` = 第 7 項（8 份成立） |
| 情境年化報酬率 | 第 14 項情境一、情境二 `本情境中年化報酬率為Y%` 的 Y = 參考條件表年利率（每處一筆；8 份成立） |

第 7 項配息淨值舉例（`假設配息率為…%`）是固定舉例文字，不是本商品配息率，不讀。

### 3.4 價格

- 共用 `derive.prices`：第 7 項標的表各標的執行價／自動提前出場價／下限觸發價 = 期初價格 × 表頭百分比，half-up 到 4 位後數值相等（8 份成立，含非整數 K % 的 NR1、NR2，以及期初價格沒有小數的日股）；列數 = 標的數；有無「下限觸發價」欄與 KI 型態一致。
- 表頭百分比就是 K／KO／KI % 的唯一出處（定義句只寫「下表所示」）；表頭讀不到 % → 轉人工覆核。
- 第 14 項百分比表每列 = 標的表表頭（`100%`／K%／KO%／KI%），列數 = 標的數（8 份成立）。
- 日期表有 `自動提前出場價` 欄時（NR2），每列 `連結標的期初價格的Y%` 的 Y = 表頭 KO %；不同 → 轉人工覆核。
- 疑似分割／除權息調整：共用規則（[BNP 核對規則](bnp-check-rules.md) §3.4）。

### 3.5 說明書內部交叉驗證（Nomura 專屬）

| 檢查 | 規則 |
|---|---|
| 商品代號第 2 處 | 封面英文名稱後 `TDCC No.` = 中文名稱後 `TDCC商品代號為`（= 檔名） |
| ISIN | 封面中文名稱後、英文名稱後、第一章第 1 項三處相同 |
| 名稱 | 封面中文名稱 = 第一章第 1 項中文名稱（忽略空白）；第一章第 1 項英文名稱 = `Nomura International Funding Pte. Ltd. {天期}-Month {CCY} Autocall Fixed Coupon Notes {記憶式}linked to {標的}(unsecured)`（發行機構在前、沒有 `issued by`；2026-10-15 確認視為正確），忽略空白 |
| 幣別 | 封面與第 5 項 `{中文}({ISO})` 相同，括號 ISO 代碼 = 中文查 `[currency]` 的結果 |
| 期數 | 日期表列數 = 天期 = 名稱 `N個月`／`N-Month` = 第 14 項 `年期` |
| KO 觀察方式 | 第 7 項 `自動提前出場決定日：` 寫法與日期表排法（D／P）一致（範本規格 §4.1） |
| Non-Call | D 型：KO 起日必須剛好等於日期表某期 `觀察期間終止日(含)`，該期別 = Non-Call；P 型：第 1～k−1 期決定日為 `不適用`、第 k 期起有日期 |
| 記憶式 | 第 7 項三種句型三選一（範本規格 §4.2）；名稱有無 `(記憶式自動提前出場)`／`with Memory Knock-Out` 與句型一致 |
| KI | 第 7 項有無下限觸發事件條款、`下限觸發決定日：` 寫法、到期贖回款數（兩款／三款）、標的表有無 `下限觸發價` 欄一致；KI P 的下限觸發決定日表日期 = 同列自動提前出場決定日 |
| 標的數 | 第 7 項單一／多標的寫法、第 8 項 `連結標的：`／`連結標的n：` 檔數、第 9 項 `彭博代碼：` 檔數與代號、名稱 `股票連結`／`連結一籃子股票` 與標的表列數一致 |
| 日期表 | 末列配息日 = 預定到期日；末列決定日（P）／觀察期間終止日（D）= 最終評價日；配息日遞增；決定日／觀察期間終止日 < 同列配息日 |
| 到期贖回 | 第 7 項 `每單位商品面額x 100.00%` 固定（無 KI：(1) 款；有 KI：(1)、(2) 款） |

### 3.7 情境分析（第一章第 14 項）

2026-10-15 確認核對：

- 設定參數：`年期` = 天期、`每單位商品面額` = 面額（含幣別）、`發行價格` = 100%（`issue_price_others`）、`固定配息率` = 第 7 項每期配息率。
- 百分比表 = 標的表表頭（§3.4）。
- 情境一、二年化報酬率 = 年利率（§3.3）。

不重算配息合計、交割股數、剩餘金額、損失率；情境三的假設價格與股數不核對。設定參數或百分比表找不到、欄數不符時轉人工覆核。

## 4. 判定原則

沿用 BARC：必核欄位抓不到、抓到多個不同值、或寫法不在範本規格內，一律轉人工覆核；「不適用」（例：無 KI）必須由說明書明確判斷（第 7 項沒有下限觸發事件條款、到期贖回只有兩款、標的表沒有下限觸發價欄）。

## 6. 樣本缺口

- P 型記憶式＋KI、D 型多標的非記憶式、單一標的記憶式、多標的 KI P、單一標的 KI D、無自動提前出場、4～5 檔標的、天期 12 個月以上、HKD／CNH／EUR／GBP／ZAR 計價、非每月配息：沒有樣本，依規則推得或轉人工覆核。
- 比價日填法（[Nomura 下單資料格式](../order-formats/nomura-fcn-reference.md) §4）依條文推得；探勘用的表比價日欄空白，實作後以回填結果請作業人員確認。
