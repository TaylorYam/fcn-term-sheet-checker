## 1. 檔名、配對與結果

| 項目 | 規則 |
|---|---|
| 分類 | 檔名（不含副檔名）須為 `<12 位商品代號>_TS` → 說明書，或 `<12 位商品代號>_IIS` → 投資人須知（結尾**剛好**相符）。不容忍空白、大小寫或其他寫法（例：`_ TS`、`_iis`、`-IIS`）。其他結尾 → 「檔名無法辨識」：需人工覆核、不能人工放行、列入錯誤清單 |
| 上手 | 和說明書相同：檔名前三碼查上手編號對照；上手沒有投資人須知範本 → 未支援上手 |
| 配對 | 檔名前 12 碼是說明書與投資人須知互相配對的依據，也用來對參考條件表 `TDCC Code`。說明書封面商品代號必須等於檔名的商品代號，不同 → 「檔名商品代號不符」（人工覆核、不能放行）；投資人須知內文有商品代號時（BARC 兩處）必須等於檔名前 12 碼，不同 → 不一致 |
| 同一列 | 參考條件表一列最多對到一份說明書與一份投資人須知；同類兩份以上 → 「多份對到同一列」（現行規則，同類才算） |
| 缺另一份 | 這批有說明書沒有同商品投資人須知（或反過來）→ 需人工覆核，原因「這批缺投資人須知」／「這批缺說明書」；屬配對問題，不能人工放行。另一份在這批裡、只是本身沒配對成功（未支援上手、範本不符等）時不算缺，但那份沒通過，說明書就不回填 |
| 狀態與放行 | 每份 PDF 各自核對、各自有狀態與錯訊、各自人工放行；PANEL 清單與錯誤清單仍是一份 PDF 一列 |
| 回填 | 一檔商品的說明書與投資人須知**都**是通過或人工放行，才回填並進「回填後」；投資人須知本身不提供任何回填值 |

## 2. 比對基準與錯訊

- 預期值出處「參考條件表」：投資人須知直接和參考條件表那一列比。錯訊：「<項目>對不起來：參考條件表 <值>／投資人須知 <值>」。
- 預期值出處「說明書」：和同商品說明書讀出的值比。錯訊：「<項目>對不起來：說明書 <值>／投資人須知 <值>」。說明書該欄讀不到時轉人工覆核，不改和參考條件表比。
- 預期值出處「審查標準」：同說明書的審查標準規則，錯訊同現行寫法。
- 說明書本來就和參考條件表比，所以三方一致；說明書錯時錯訊只出現在說明書那份。
- 項目名稱沿用說明書的名稱（例：「發行日」「UL_1 執行價」）；錯誤清單與 PANEL 以 PDF 檔名分辨是哪一份。

## 4. 不核對項目

說明書有、投資人須知沒有（不核對）：

- BARC、HSBC：交易日、最終比價日與比價日、Non-Call、KO 觀察方式、KI 型態與 KI%、配息表與提前出場表、情境試算、審查通過日期、受託機構負責人；HSBC 另外沒有商品代號、ISIN、價格、年利率、最低申購金額、發行價格。記憶式只表現在商品名稱（B6 已涵蓋）。
- MS：商品代號、面額、最低申購金額、發行價格、標的彭博代碼、年利率、各標的價格與執行／下限／KO %、日期表與比價日、情境試算、審查通過日期、受託機構電話與負責人。
- BNP：發行價格、年利率、日期表與比價日、P 型的第一個可提前出場期、情境試算、最低加購／贖回金額、審查通過日期、受託機構負責人。
- SG：最低申購／加購／贖回金額、日期表與比價日、D 型的第一個可提前出場期、情境試算、審查通過日期、受託機構電話與負責人。

投資人須知有、但不核對（說明書也不核對）：發行機構信用評等、銷售說明書／MTN 計劃日期、總代理人與發行人資訊、提前贖回受理日、各段說明文字；MS 另有發行機構地址、方案備忘錄日期、受託對象、後續受理贖回日期，以及收益分配事項的配息期別「j 係為 a 至第 N」（天期與 Non-Call 已核對，2026-10-09 確認不核對）；BNP 另有標的中文名稱、交易所、`貨幣(Currency)` 列（同 BNP 說明書決定 C）、保證機構與總代理人地址、總代理人名稱、基本公開說明書日期、銷售對象、發行評等、保本率、開始／後續受理贖回日（只有文字）、申購贖回截止時間（2026-10-14 確認不核對）；SG 另有標的中文名稱與資產種類、保證機構信用評等、發行評等、受託及銷售對象、國外相當交易條件、保本率、開始受理贖回日期（只有文字）、後續受理贖回日期、發行機構／保證機構／總代理人地址、總代理人簡稱、收益分配與贖回價金的說明文字（2026-10-14 確認不核對）。

未涵蓋（列入「待處理」）：範本規格樣本總表以外的型態（例：HSBC 有 KI 的投資人須知；MS、SG 同各自說明書未涵蓋的型態）。遇到時範本未涵蓋的段落、欄頭或寫法轉人工覆核。
