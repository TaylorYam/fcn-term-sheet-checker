# 投資人須知核對規則

- 適用：BARC（[`barc-zh-iis`](../templates/barc-zh-iis.md)）、HSBC（[`hsbc-zh-iis`](../templates/hsbc-zh-iis.md)）中文投資人須知
- 決策：[ADR 0007](../adr/0007-iis-paired-with-term-sheet.md)；名詞見 [CONTEXT.md](../../CONTEXT.md)
- 狀態：2026-10-08 與使用者確認（grill-with-docs）；尚未實作
- 依據：SOP「結構債TS、IIS 核對SOP」（IIS 共 4 頁；產品條件、風險等級、警語、受託機構等與說明書相同）＋ 每家 1 份樣本探勘

## 1. 檔名、配對與結果

| 項目 | 規則 |
|---|---|
| 分類 | 檔名（不含副檔名）結尾**剛好**是 `_TS` → 說明書；**剛好**是 `_IIS` → 投資人須知。不容忍空白、大小寫或其他寫法（例：`_ TS`、`_iis`、`-IIS`）。其他結尾 → 「檔名無法辨識」：需人工覆核、不能人工放行、列入錯誤清單 |
| 上手 | 和說明書相同：檔名前三碼查上手編號對照；上手沒有投資人須知範本 → 未支援上手 |
| 配對 | 檔名前 12 碼對參考條件表 `TDCC Code`，同時也是說明書與投資人須知互相配對的依據。投資人須知內文有商品代號時（BARC 兩處）必須等於檔名前 12 碼，不同 → 不一致 |
| 同一列 | 參考條件表一列最多對到一份說明書與一份投資人須知；同類兩份以上 → 「多份對到同一列」（現行規則，同類才算） |
| 缺另一份 | 這批有說明書沒有同商品投資人須知（或反過來）→ 需人工覆核，原因「這批缺投資人須知」／「這批缺說明書」；屬配對問題，不能人工放行 |
| 狀態與放行 | 每份 PDF 各自核對、各自有狀態與錯訊、各自人工放行；PANEL 清單與錯誤清單仍是一份 PDF 一列 |
| 回填 | 一檔商品的說明書與投資人須知**都**是通過或人工放行，才回填並進「回填後」；投資人須知本身不提供任何回填值 |

## 2. 比對基準與錯訊

- 預期值出處「參考條件表」：投資人須知直接和參考條件表那一列比。錯訊：「<項目>對不起來：參考條件表 <值>／投資人須知 <值>」。
- 預期值出處「說明書」：和同商品說明書讀出的值比。錯訊：「<項目>對不起來：說明書 <值>／投資人須知 <值>」。說明書該欄讀不到時轉人工覆核，不改和參考條件表比。
- 預期值出處「審查標準」：同說明書的審查標準規則，錯訊同現行寫法。
- 說明書本來就和參考條件表比，所以三方一致；說明書錯時錯訊只出現在說明書那份。
- 項目名稱沿用說明書的名稱（例：「發行日」「UL_1 執行價」）；錯誤清單與 PANEL 以 PDF 檔名分辨是哪一份。

## 3. 檢查點

✓ = 範本有此項，要核對；— = 範本沒有，不核對（不推定通過，也不報缺漏）。範本有、但這份讀不到 → 轉人工覆核。

| # | 檢查點 | BARC | HSBC | 預期值 | 不符時 |

| A1 | 頁數剛好 4 頁 | ✓ | ✓ | 4（使用者 2026-10-08：比外規「不超過 5 頁」嚴格） | 不一致 |

## 4. 不核對項目

說明書有、投資人須知沒有（不核對）：交易日、最終比價日與比價日、Non-Call、KO 觀察方式、KI 型態與 KI%、配息表與提前出場表、情境試算、審查通過日期、受託機構負責人；HSBC 另外沒有商品代號、ISIN、價格、年利率、最低申購金額、發行價格。記憶式只表現在商品名稱（B6 已涵蓋）。

投資人須知有、但不核對（說明書也不核對）：發行機構信用評等、銷售說明書／MTN 計劃日期、總代理人與發行人資訊、提前贖回受理日、各段說明文字。

未涵蓋（列入「待處理」）：BARC 多標的、有 KI、記憶式的投資人須知寫法；HSBC 其他型態。遇到時範本未涵蓋的段落或欄頭轉人工覆核。

## 5. 決策紀錄

| 日期 | 決策 |
|---|---|
| 2026-10-08 | 每檔商品有說明書（`_TS`）與投資人須知（`_IIS`），兩份一起核對，都通過或人工放行才回填（ADR 0007） |
| 2026-10-08 | 投資人須知必須剛好 4 頁；5 頁也判不一致 |
| 2026-10-08 | 檔名結尾嚴格比對，不容忍空白；不符為「檔名無法辨識」，不能放行 |
| 2026-10-08 | 三方一致：參考條件表有的欄位和參考條件表比，沒有的和說明書比 |
| 2026-10-08 | 缺同商品的另一份屬配對問題，不能放行；每份 PDF 各自放行 |
| 2026-10-08 | 檢查點依各上手投資人須知實際內容列舉（§3），審查標準類也核對 |
| 2026-10-08 | 期初定價為 VWAP 的商品，參考條件表價格欄不比對（Issue #122），投資人須知的價格改和說明書比 |
