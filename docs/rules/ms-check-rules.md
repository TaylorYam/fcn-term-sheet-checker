# 核對規則：MS 中文產品說明書

- 文件側：[MS 範本規格](../templates/ms-zh-product-description.md)
- 下單側：參考條件表，見[參考條件表格式](../order-formats/reference-sheet.md)與 [MS 下單資料格式](../order-formats/ms-fcn-reference.md)
- 會隨時間改變的基準見[審查標準](review-standard.md)（設定檔 `config/review_standard.toml`）
- 狀態：核對範圍與規則已與作業人員確認（2026-10-08，Issue #132）；已實作（Issue #135，`src/fcn_checker/parsers/ms*.py`、`src/fcn_checker/rules/ms*.py`），rule_id 對照見 §9
- 本文件只寫與 [BARC 核對規則](barc-check-rules.md)、[HSBC 核對規則](hsbc-check-rules.md)不同或 MS 特有的部分；未提到的原則（判定原則、數值處理、標的只核對彭博代號、期初價格本身不核對等）沿用 BARC

## 1. 範圍

- 只支援新版範本（2025-10 起的樣本；以 2026 年後的文件為準）。舊版（2022–2023）範本辨識失敗，轉人工覆核，不另做規則（2026-10-08 確認）。
- 只核對說明書（TS）。MS 投資人須知（IIS）在本規格合併後另開 Issue；在那之前 MS 的投資人須知為「未支援上手」，所以 MS 商品不會打 `TS`／`IIS` 的 `V`、也不會回填（ADR 0007）。

## 2. 不核對的項目

- 沿用 BARC／HSBC：整理表存續或內部欄位、方案備忘錄日期、信用評等、發行機構方負責人、財報、情境分析的股數／零股／假設收盤價／到期贖回價值、較差情境的年化報酬率。
- 總代理人（台灣摩根士丹利）名稱、電話、地址、負責人（2026-10-08 確認）。
- 受託機構設立日期（2026-10-08 確認；沒有獨立標準）。
- 封面 7、8、11、12（註冊地、發行機構地址、報價機構）、第一章 §4、§8–§10、§12、§13、§19–§29、第五章、第六章。
- 發行日 − 交易日、到期日 − 期末定價日的天數（只作參考）。
- Non-Call = 天期的 P 型：參考條件表 `KO(%)`、`UL_n_KO價`（說明書沒有，見 [MS 下單資料格式](../order-formats/ms-fcn-reference.md) §3）。

### 3.3 年利率與月配息率（MS 專屬，讀參考條件表）

說明書沒有年利率（2026-10-08 確認以下核對方式）：

| 檢查 | 規則 |
|---|---|
| 月配息率 | §15(2) `固定配息率 (X%)`、D 型 §15 `{X%×n(j)/N(j)}`、§18 假設 `月配息率=X%`、§18 每個情境算式中的 `×X%`：每處都 = 參考條件表 `Coupon p.a. (%)` ÷ 12，四捨五入（half-up）到 4 位 |
| 年利率 | §18 獲利情境（標題不含 `較差` 的情境）每處 `年化報酬率為Y%` = 參考條件表年利率（2 位） |

這兩條要讀參考條件表的年利率，屬 [ADR 0005](../adr/0005-issuer-adapter-and-shared-rules.md) 的例外：MS 在 `reference_fields` 宣告 `coupon_pa_pct`（同 BARC 宣告年利率與天期的做法）。6 份新版樣本全部成立。

### 3.4 價格

- 共用 `derive.prices`：§16 各標的執行價／下限價／KO 價 = 期初價格 × 表頭百分比，half-up 到 4 位；價格表列數 = 標的數；有無下限價欄與 KI 型態一致（6 份成立）。
- MS 專屬：有「自動提前出場價」欄 ⇔ Non-Call < 天期（範本規格 §4.6）。
- §16 價格表的彭博代碼依序 = 第一章 §11 標的表。

### 3.6 固定警語與名稱（審查標準 MS 版本）

**固定風險警語**（2026-10-08 確認為 MS 特例，視為正確）：

- MS 版本 = 現行 `risk.fixed_warning` 去掉【】（`【RR4】`→`RR4`、`【證券交易所交易證券】`→`證券交易所交易證券`），結尾到 `(專業投資人與OSU客戶以下合稱「投資人」)` 為止（封面與第三章後面沒有句號）。
- 第一章 §2 開頭為 `本商品風險程度為RR4。`（少「等級」），其餘相同；這一處的寫法也視為正確。
- 出現次數合計 3 次（封面、第一章 §2、第三章各 1）。
- 實作時新增 `risk.fixed_warning_by_issuer.ms`，並以設定（不寫死在程式）表達第一章 §2 允許的開頭寫法。

**商品名稱樣板**（`product_name.ms`，依 6 份新版樣本推得，2026-10-08 確認照此核對）：

- 中文：`英商摩根士丹利發行{tenor}個月期{ccy_zh}計價連結{標的寫法}固定配息{memory_zh}結構型商品(無保證機構)(無擔保)(不保本)(下稱「本商品」)`
  - `{標的寫法}`：1 檔 `股票或指數股票型基金`；2 檔以上 `一籃子股票與/或指數股票型基金`
  - `{memory_zh}`：記憶式時 `（記憶式自動提前出場）`
- 英文：`Morgan Stanley & Co. International Plc issuance of {tenor} Months {ccy} Fixed Coupon Notes linked to {標的寫法} (non-guaranteed)(unsecured)(non-principal protected)`
  - `{標的寫法}`：1 檔 `Shares or ETFs`；2 檔以上 `Worst of Shares and/or ETFs`

- 比對：中文忽略空白、括號全半形不計；英文忽略所有空白（換行處黏字）。
- 「1 檔／多檔」是兩組不同字串，不是現有 `{maxi_*}` 那種「多檔才加前綴」；實作時要新增佔位符（例如單一與一籃子各一組設定值），並更新[審查標準](review-standard.md) §2.3。

### 3.7 情境分析（§18，MS 專屬）

2026-10-08 確認納入情境金額（決定 A）。MS 的總配息是「已進位的每期配息 × 期數」（文件算式寫成 `A 美元×k`，例：每期 `100.00 美元×2`），**與 HSBC 用未進位年利率推算後再進位不同**。

| 檢查 | 規則 |
|---|---|
| 假設 | `總投資金額 = 1 單位商品面額 = N 美元` = 面額；`年期：N 個月` = 天期；`月配息率=X%` = §3.3 |
| 每期配息 | 每處 `面額 × X% = A 美元`（含 D 型 `×X%×100%`）：A = 面額 × 月配息率，half-up 到 2 位 |
| 獲利情境損益 | `面額 + A × k − 面額 = B`：k = 算式中 `A 美元×k` 的 k（沒寫時為 1），須等於該情境假設的配息次數（`假設在第k 個配息週期終止日`／`第k 個定價日`；一般情況與 S05 型的較佳情況 = 天期）；B = A × k，完全相等 |
| 獲利情境年化報酬率 | = 年利率（§3.3） |
| 較差情境 | 每期配息同上；總配息 `A × 天期`；損益只驗算式加總：`A × 天期 + 文件寫的到期贖回價值 − 面額 = 文件寫的損益`。贖回價值、股數、零股、假設收盤價、年化報酬率不核對 |

情境標題與期數寫法未知、或算式找不到時轉人工覆核，不跳過後宣稱通過。

## 4. 判定原則

沿用 BARC：必核欄位抓不到、抓到多個不同值、或寫法不在範本規格內，一律轉人工覆核；「不適用」（例：無 KI、Non-Call = 天期時沒有 KO 欄）必須由說明書明確判斷。

## 6. 待確認事項與樣本缺口

- 沒有非美元的 MS 說明書樣本（參考條件表有 JPY、AUD、ZAR 的 MS 商品）：幣別名稱、面額預設值、名稱樣板依規則推得，待樣本驗證；遇到審查標準幣別表沒有的幣別照共用規則轉人工覆核。
- 新版每期觀察 KI（`P`）、P 型非記憶式且 Non-Call < 天期、D 型 Non-Call > 1、5 檔標的：沒有樣本，依規則推得。
- MS 投資人須知：另開 Issue（本規格合併後）。
- 第二章受託機構營業所在地少「松山區」（§5，6 份皆同）：若確認視為正確，在審查標準加地址的等價寫法（同 `distributor.phone_equivalents` 的做法，只改設定）；在那之前每份 MS 說明書都會有這筆不一致，需人工放行。
