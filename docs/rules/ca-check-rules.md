- 發行機構註冊辦公地點、註冊地；計算代理機構、交易商、付款代理機構、結算機構。

- 發行日 − 交易日、到期日 − 期末訂價日的天數（只作參考；到期日和參考條件表比）。

## 3. 核對規則

### 3.1 參考條件表欄位（共用 `rules/reference.py`）

語意與 rule_id 同 BARC。CA parser 只負責交出標準欄位；來源見 [CA 下單資料格式](../order-formats/ca-fcn-reference.md) §2。

| 標準欄位 | 規則（rule_id） | CA 差異 |
|---|---|---|
| 商品代號、ISIN、幣別、面額、各日期、天期、百分比、KO／KI 型態、Non-Call、比價日 | 共用（`field.*`、`backfill.*`） | 代號只有封面 1 處；ISIN 取封面中文名稱後（三處須相同，§3.5）；**交易日取第 13 項 `期初訂價日`**（說明書沒有「交易日」標籤）；K／KI／KO % 取第 9 項價格表表頭（說明書沒有文字定義）；KI 欄位來自「下限價」；KO 有 D、P 兩型（範本規格 §4.1）；KI 有 AM、D、無（範本規格 §4.4） |

### 3.3 配息率（2026-10-15 確認）

| 檢查 | 規則 |
|---|---|
| 年利率 | 第 16 項基本假設 `年化配息率為y%` 的 y = 參考條件表 `Coupon p.a. (%)`（共用 `field.coupon_pa_pct`） |
| 月配息率 | 第 9 項配息表每列 `配息率` x 相同，且 = y ÷ 12 四捨五入（half-up）到 4 位（5 份成立） |
| 其他出處 | 第 16 項基本假設 `配息率：x%` = 配息表 x；第 15 項 `(4)最低保證配息率：第一個月／前k個月配息 x%` 的 x = 配息表 x、月數 = Non-Call（5 份成立） |
| 配息頻率 | 配息表列數 = 天期（每月一期）；不同判不一致（`doc.coupon_periods`，同 Natixis；樣本都是每月） |
| `n/N` | KO 每日型提前出場當期按預定交易日數比例配息：不推算（只作型態佐證） |

### 3.4 價格與百分比

- 共用 `derive.prices`：第 9 項價格表各標的執行價／下限價／自動提前出場價 = 期初訂價 × 百分比，half-up 到 4 位後數值相等（5 份成立，含非整數 K % 與日股）；列數 = 第 10 項標的數；有無下限價欄與 KI 型態一致。
- **表頭 % 是 K／KI／KO % 的唯一來源**（說明書沒有 `執行價為期初訂價之X%` 這類文字定義）：第 9 項表頭 = 參考條件表（共用 `field.*`）、= 第 16 項情境價格表表頭（§3.7）。**欄序 K → KI → KO**，依表頭關鍵字順序決定，不可寫死。表頭讀不到 % → 轉人工覆核。
- 期初訂價一律 4 位小數。
- 疑似分割／除權息調整：共用規則（[BNP 核對規則](bnp-check-rules.md) §3.4；樣本沒有這種情形）。

### 3.5 說明書內部交叉驗證（CA 專屬）

| 檢查 | 規則 |
|---|---|
| 名稱 | 封面 `商品中文名稱` = 第一章第 1 項中文名稱（忽略空白，都截到 `(ISIN：` 之前） |
| ISIN | 封面中文名稱後、英文名稱後、第一章第 1 項名稱後三個 `(ISIN：…)` 相同 |
| 幣別 | 封面 `計價幣別` = 第一章第 5 項（`{中文}({ISO})`，中文查 `[currency]` = ISO） |
| 期數 | 配息表列數 = 天期 = 名稱 `N 個月`／`N-Month` = 情境基本假設 `天期：N 個月` |
| KO 型態 | 第 9 項 `(b)` D 型寫法 ⇔ 配息表有 `配息期結束日` 欄；P 型 ⇔ 有自動提前出場觀察日表（範本規格 §4.1、§5.2） |
| Non-Call | D：k ≤ 配息表列數；P：觀察日表第 1 列出場日在配息日表內，且觀察日表列數 = 天期 − Non-Call + 1；第 15 項 (4) 月數 = Non-Call；情境一配息月數 `第 1`／`第 1~k` 的 k = Non-Call |
| 記憶式 | 第 9 項 `(b)` 兩句都有 = Y、都沒有 = N；只有一句、或多標的又沒有兩句 → 轉人工覆核（範本規格 §4.2） |
| KI | 第 9 項 `(c)` 有無 `若未發生界限事件`、`(2)` 有無 `界限事件：` 定義、價格表有無下限價欄三者一致（範本規格 §4.4） |
| 日期表 | 配息表列數 = 天期、期別連續、配息日遞增、末列配息日 = 到期日；D：末列配息期結束日 = 期末訂價日、結束日 < 同列配息日；P：觀察日表末列 = 期末訂價日／到期日、出場日都在配息日表且期別連續、觀察日 < 同列出場日 |
| 情境價格表 | 第 16 項情境價格表逐格（期初訂價與各價格）= 第 9 項價格表、表頭 % = 第 9 項（§3.7） |

### 3.7 情境分析（第一章第 16 項(3)）

2026-10-15 確認核對：

- 基本假設 `天期：N 個月` = 天期；`每單位面額：X幣別` = 第一章第 6 項面額；`配息率：x%(年化配息率為y%)`：x = 配息表、y = 年利率。
- 情境價格表逐格 = 第 9 項價格表（期初訂價、執行價、下限價、自動提前出場價；欄序與表頭 % 同第 9 項；情境表沒有列號欄）。
- 情境一 `假設於第1 個自動提前出場觀察日發生自動提前出場事件。` 的配息月數 `第 1`／`第 1~k`：k = Non-Call。

不重算配息金額、累積配息、股數、剩餘金額、總報酬率、平均年化報酬率；假設匯率不核對；情境二、三的條件句不核對。找不到基本假設或情境價格表 → 轉人工覆核。

### 3.8 最低申購與贖回（2026-10-15 確認）

- 第四章 4. `最低申購金額： X幣別(相當於一單位(張)商品)`、`最低累加申購金額：商品面額X幣別(相當於一單位(張)商品)`：最低申購、最低加購 = X。
- 第四章 8. `最低贖回金額或單位(張)數：不得小於X幣別(相當於一單位(張)商品)…`：最低贖回 = X。
- 不設 `min_amount_multiples.ca`：三項倍數都是預設 1（5 份都是 1 單位，不分幣別）。

## 4. 判定原則

沿用 BARC：必核欄位抓不到、抓到多個不同值、或寫法不在範本規格內，一律轉人工覆核；「不適用」（例：無 KI）必須由說明書明確判斷（`(c)` 直接比執行價、沒有 `界限事件：` 定義、價格表沒有下限價欄）。
