## 2. 不核對的項目（沿用 BARC 與使用者確認）

- 整理表存續或內部欄位：庫存狀態、當日比價、Product、私銀註記、UF、UL_n_Memo、無表頭欄。
- MTN 計劃與投資說明書日期、發行機構信用評等、發行機構方負責人、情境分析股數、零股及最差情境完整贖回重算、有利／最差情境年化報酬率（其餘依 §3.7）。
- Nt（各期預定交易日數，計算代理機構決定）。
- 交易日→發行日、最後評價日→到期日、決定日→付款日的天數間隔（只作參考）。
- P 型提前出場表的「計息期間」欄（流水號，見 §3.4）。

## 3. 核對規則

### 3.1 範圍

沿用 BARC：**只要是變動參數就要核對**。整理表有的直接比；沒有的用推導關係或說明書內部交叉驗證。

### 3.2 標準欄位對照

| 標準欄位 | 整理表欄位 | 說明書來源（範本規格） | 規則 |
|---|---|---|---|
| 商品代號 | TDCC Code | 封面 | 字串相等；也用來配對 |
| ISIN | ISIN Code | §27 | 字串相等（整理表有值，HSBC 核對） |
| 幣別 | 承作幣別 | 封面 | 審查標準幣別對照 |
| 單位面額 | 單位面額 | §6 | 整數相等；另依審查標準面額預設值，不等於預設值轉人工審查 |
| 交易日、發行日、最後評價日、到期日 | 交易日／發行日／最終比價日／到期日 | §15 | 日期相等 |
| KO % | KO(%) | §11(2) | 數值相等 |
| KO 觀察方式 | KO(Freq) | §4.2 | `D`／`P` |
| 記憶式 | KO(memo) | §4.1 | `Y`／`N` |
| 執行 % | K(%) | §11(3) | 數值相等 |
| KI % | KI(%) | §11(3) | 有 KI 時數值相等；無 KI 時整理表為 `-` |
| KI 型態 | KI(Freq) | §4.4 | `-`／`AM`／`D` |
| 年利率 | Coupon p.a. (%) | §11(1) | 數值相等（比到 2 位；說明書寫 4 位） |
| 天期 | 天期(月) | §15(1) | 整數相等 |
| 第一個可提前出場期 | Non-Call(月) | §4.3 | 整數相等 |
| 各期比價日 | 比價日_1～12 | §11(1)(2) | 見 [HSBC 下單資料格式](../order-formats/hsbc-fcn-reference.md) §4 |
| 標的 | UL_1～5 | §12(1) 彭博代號 | 依順序逐字相等（含交易所尾碼），數量相同 |
| 各標的價格 | UL_n_進場價／執行價／下限價／KO價 | §12(1) | 整理表四捨五入（half-up）到 4 位後相等 |

### 3.3 數值

- 月配息率：說明書只寫年利率（§11(1) `X% × 1/12`）；§18 情境分析的 `固定配息率為 Y%` 必須 = 年利率 ÷ 12 四捨五入（half-up）到 4 位（8 份成立）。
- 價格：§12(1) 各標的執行價、KO 價、下限價 = 期初股價 × 對應百分比，half-up 到 4 位（8 份成立）。

### 3.4 提前出場期別（2026-10-01 確認）

- P 型提前出場表的「計息期間」欄是流水號，不代表期數。**以「提前出場付款日 = 配息表付息日」決定期數**，不比對該欄，也不轉人工。
- 提前出場表每一列的付款日都必須是某期付息日，且列為連續的期別直到末期；否則轉人工覆核。
- D 型：KO 起日必須等於某期終止日，該期即第一個可提前出場期；找不到對應期轉人工覆核。

### 3.5 說明書內部交叉驗證

| 檢查 | 規則 |
|---|---|
| 配息期數 | `配息期數 = N` = 配息表列數 = 天期 = 封面名稱月數 |
| 付息日 | 逐期遞增；末期付息日 = 到期日 |
| D 型配息表 | 終止日 < 付息日；末期終止日 = 最後評價日；第一個可提前出場期（含）以前起始日與 Nt 為 `-`，之後有值；起始日 = 前期終止日後 1 個平日（只排除週末） |
| P 型提前出場表 | 決定日 < 付款日；付款日 = 同期付息日；末列決定日 = 最後評價日 |
| 百分比 | §12(1) 表頭 `(即期初股價的X%)` = §11 定義句；有「觸及不保本價格」欄 ⇔ §11(3) 有 KI 定義 |
| 記憶式 | 名稱含「記憶式」⇔ §11(2) 為「鎖定股票」寫法 |
| 情境分析 | §18 重印價格表 = §12(1)（代號與各價格逐格相等）；§18 月配息率 = 年利率 ÷ 12 |
| 面額 | §7 最低交易金額、第四章 §5 最低申購金額與最低加購金額 = 面額 |
| 申購日期 | 第四章 §1 商品開始受理申購日、申購結束受理日 = 交易日 |

### 3.6 文件資訊與用語

| 項目 | 規則 |
|---|---|
| 受託機構審查通過日期 | = 審查標準 `approval_date` |
| 刊印日期 | 參考性審閱版與最終版刊印日期都在交易日當天到交易日 + 1 之內 |
| 風險等級 | = 審查標準（RR4） |
| 固定風險警語 | 審查標準 `risk.fixed_warning_by_issuer.hsbc`，忽略空白後逐字比對，出現 3 次 |
| 「受託投資」 | 只能出現在允許片語內（含 HSBC 的「受託投資、受託買賣或為投資型保單」） |
| 受託機構負責人 | 第二章受託或銷售機構段落 = 審查標準（林晋輝，古字晋） |
| 中文商品名稱 | 審查標準 `product_name.hsbc.zh`；括號全半形不計 |
| 英文商品名稱 | 審查標準 `product_name.hsbc.en`（Maxi／Daily／Memory 前綴）；忽略所有空白 |
| 範本辨識 vs 商品代號前綴 | 商品代號前 3 碼 `325` 對應 HSBC；與範本辨識結果不一致轉人工覆核 |


### 3.7 雙方螢光範圍補齊（2026-10-02，Issue #34）

開發者先完成 H08、H02、H06、H04、H05 的獨立標記與清單並凍結，之後才讀取作業人員 H02 版本。使用者明確指定只畫一份，因此 H02 是唯一雙方對照樣本；其餘四份僅供開發者探勘與型態驗證，不宣稱為交集。此安排依使用者要求縮小上手規範 §3 的作業標記範圍。PDF、原文、真實值與 hash 紀錄只留本機 `data/tmp/`。

交集按欄位與條款語意判斷，部分涵蓋不等於整段皆已核對；同值異處分開。使用者要求開發者自行整理既有決定與結構檢查，只詢問重要未決項目。§3.2–§3.6 已確認規則繼續保留；以下補齊 H02 對照的差異。

| 分類／位置 | 核對範圍 | 基準與處理 |
|---|---|---|
| 交集：封面／§1、§5–§7、§11、§12、§15、§18、第二章、第三章、第四章 | 商品代號、共同名稱欄位、幣別、面額、利率、期數、日期、KI／執行比例、彭博代號與價格、警語、審查日期、負責人、申購日期 | §3.2–§3.6；每個正式與重複出現處各自核對，不以主來源通過代替 |
| 作業人員專有：H02-O004、O050、O052 | 受託或銷售機構名稱、電話、地址；封面及第二章各自比對 | 審查標準 `distributor.name/phone/address`；忽略排版空白與換行。電話允許已確認的台灣國際／國內等價形式，其餘未知格式轉人工 |
| 作業人員專有：H02-O014、O028 | 發行價格及情境重印值 | 沿用共用 SOP `issue_price.pct`；不等於固定值轉人工；情境重印值與正式發行價格一致 |
| 作業人員專有：H02-O057–O059 | 申購、提前贖回、分銷費用範圍 | 沿用共用審查標準 `fees`，費用列各自比對，不只查表格有值 |
| 開發者專有／部分涵蓋：H02-D001、D003、D005、D010、D043–D053、D056–D063、D082、D156、D163–D164 | 完整中英文名稱、發行機構名稱、KO／KI 定義與觀察、表頭百分比、正式天期、ISIN、最低申購及加購金額 | 名稱／發行機構用依上手固定標準；其他沿用 §3.2–§3.6；結構檢查預設保留。不擴充外部標的名稱或交易所對照表 |
| 部分涵蓋：H02-O021、O032 | 正式與情境價格表中的標的幣別、交易所 | 僅核對兩表同一標的內部一致，不宣稱外部正確性；標的幣別不直接等於商品幣別 |
| 部分涵蓋／重複處：H02-O026–O035、O037–O040、O042–O045、O047–O049 | 各情境每次出現的天期、期別、配息次數、面額、月配息率、執行／KI 價格；初始投資、本金、配息、簡單投資損益算式 | 正式條款、整理表及情境明列條件；每處核對。單期金額由面額 × 未進位年利率 ÷ 12 推得；總配息由面額 × 未進位年利率 ÷ 12 × 該情境配息期數推得，金額最後 half-up 到 2 位，不用已進位單期金額累乘 |
| 部分涵蓋：H02-O018 | P 型 KO 表流水號 | 不核對為期數；以付款日對應付息日求期別，沿用既有決定 |
| 作業人員專有：H02-O051；H02-O036、O041、O046 | 受託機構設立日期；情境年化率 | 設立日期維持不核對（無獨立標準）；一般持有至到期、全部配息情境的年化率沿用 BARC 核對正式年率，有利／最差情境年化率不核對 |
| 開發者上下文：H02-D054、D087–D088、D092 等 | BFIX 定位句、情境假設匯率／每期交易日數、沒有有效欄位的標題 | 不列核對規則；保留凍結原檔，不修改以迎合作業版本。假設值只作可辨識的算式輸入，不驗證外部正確性 |

金額、百分比與期數以 Decimal／整數處理。簡單損益逐式按該情境已確認的本金、配息、初始投資計算；股數、零股、最差情境贖回完整重算不在範圍，不能把它們的未驗證結果當成已核對的上游。日期／格式／來源／缺漏／歧義等結構檢查保留。應有的出處抓不到、有歧義、公式／期別寫法未知，一律轉人工覆核，不跳過後宣稱通過。

新增規則必須有合成反例，尤其是「正式值正確、某次重印錯誤」、「總配息錯用已進位單期金額乘期數」及「一般年化率混入有利／最差情境」。真實樣本若出現新差異須逐一列出，不能直接套用舊探勘的零差異結論。

## 4. 判定原則

沿用 BARC：必核欄位抓不到、抓到多個不同值、或寫法不在範本規格內，一律轉人工覆核；「不適用」（例：無 KI）必須由說明書明確判斷。
