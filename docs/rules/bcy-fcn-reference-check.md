## 2. 不核對的欄位（使用者確認）

`庫存狀態`、`當日比價`、`私銀註記`、`UF`、`UL_n_Memo`、`BV` 欄。這些是存續或內部資訊，TS 裡沒有對應資料。`UL_n_Memo` 看起來是存續期間各標的的記憶狀態，`BV=1` 與「已於…KO」同列出現。

## 3. 已確認的核對規則（2026-10-01）

### 3.1 範圍

**只要是變動參數（不是每份 TS 都一樣的）就要核對。** 有 Excel 欄位的直接比；Excel 沒有的，用推導關係或 PDF 內部交叉驗證。

### 3.2 欄位對照與規則

| Excel 欄 | PDF 來源（見範本規格） | 規則 |
|---|---|---|
| TDCC Code | p1 商品代號 | 字串相等 |
| ISIN Code | p1 ISIN | 字串相等 |
| 發行機構 | p1 發行機構含 `Barclays Bank PLC` | 對應為 `Barclays` |
| 單位面額 | §6 面額 | 整數相等 |
| 承作幣別 | p1 計價幣別 | `美元→USD`、`日幣→JPY`、`人民幣→CNH`；不在對照表內的幣別轉人工覆核 |
| 交易日、發行日、最終比價日、到期日 | §13(2)(3)(4)(5) | 日期相等 |
| 比價日_1～12 | §13 提前出場觀察日 | 見 §3.3 |
| KO(%) | §15 觸發百分比 | 數值相等 |
| KO(Freq) | §13 表頭型態 | 期間觀察 `D`、定日 `P` |
| KO(memo) | 商品名稱含 `記憶式` | `Y`／`N` |
| K(%) | §15 執行百分比 | 數值相等 |
| KI(%) | §15 觸及生效百分比 | 數值相等；PDF 無定義時 Excel 必須是 `-` |
| KI(Freq) | §15 是否有 `觸及生效評價日` | 有 → `D`；只有觸及生效價格 → `AM`；無 KI → `-` |
| Coupon p.a. (%) | §14 年利率 | 數值相等 |
| 天期(月) | §13(1) 年期 | 整數相等 |
| Non-Call(月) | §13 表格推導（範本規格 §4.3） | 整數相等 |
| UL_n | §10 彭博代號去掉 ` Equity` | 依表格順序逐一相等；兩邊標的數量也要相同 |
| UL_n_進場價／執行價／下限價／KO價 | §15 價格表 | 見 §3.4 |

### 3.3 比價日填法（固定規則）

- **P（定日觀察）**：每個可以提前出場的期別都要填，等於該期評價日；不可提前出場的期別填 `-`。
- **D（期間觀察）**：只填「第一個可以提前出場的期別」和「最後一期」，等於該期的 `期末日`；其他期別填 `-`。
- 該填的位置沒填，或不該填的位置有值，都算不一致。

### 3.4 數值與小數位

- Excel 數字可能有二進位浮點尾數（例：`x.xx64999999994`），先四捨五入到 9 位小數清掉尾數。
- 價格：再四捨五入（half-up）到 4 位小數，跟 PDF 相同就算一致。Excel 可能存未四捨五入的計算值（例：6 位小數），也按這個規則處理。
- 百分比：比到 PDF 顯示的位數（2 位）。

### 3.5 月配息率（2026-10-01 確認）

- **總配息率是正確值**：總配息率 = Excel 年利率 × 天期 ÷ 12。
- 推算月配息率 = 總配息率 ÷ 商品期數（期數 = PDF 配息表列數，目前每月一期，等於天期）。
- 推算值與 PDF 月配息率**差距 ≤ 0.0001 視為一致**；超過才判不一致。

背景：用上式四捨五入到 4 位，14 份樣本中有 4 份（S06、S08、S10、S12）比 PDF 少 0.0001（例：年利率 10.00% → 推算 0.8333%，PDF 0.8334%）；沒有任何單一進位方式能讓 14 份全部吻合，因此採用容差。

PDF 內部另外要求：月配息率在 §9(1)、§14、§15(2)、§17(1) 都相同；年利率在 §9(1)、§14、§17(1) 都相同。

### 3.6 標的（2026-10-01 確認）

上手（發行機構）以**彭博（BB）英文代號為準**，再依代號對應的中文名稱填寫說明書。因此：

1. 先比代號：PDF §10 彭博代號（去掉 ` Equity`）= Excel `UL_n`，依順序逐一相等，數量也要相同。
2. 再用代號查「標的對照表」取得中文名稱與交易所：
   - PDF §10、§15（及 §11、§16）的中文名稱 = 對照表中文名稱；
   - PDF §10 交易所 = 對照表交易所。
3. 代號不在對照表內 → 轉人工覆核，不從 PDF 反推名稱。

標的對照表欄位：`bb_ticker`（例 `XXX UN`）、`name_zh`、`exchange_zh`。注意：

- 同一家公司不同股票類別可能共用中文名稱（例：A 股與 C 股都寫同一個公司名），所以**主鍵只能是代號**，不能用名稱反查。
- 「中文名稱」欄可能是英文（說明書直接用英文公司名），比對時照原字串比，不翻譯。
- 英文名稱在 PDF 中可能換行，合併時要補回空白。

目前對照表草稿由 14 份樣本建立（15 個代號，各代號在所有樣本中的名稱與交易所都一致），存在本機 `data/tmp/`；正式來源與維護方式見 §6.2。

### 3.7 PDF 內部交叉驗證（Excel 沒有對應欄位）

| 檢查 | 規則 |
|---|---|

| 配息日期 | 每列評價日 < 支付日；支付日逐期遞增 |

## 4. 判定原則

- 任何必核欄位抓不到、抓到多個不同值、或型態不屬於範本規格列出的寫法，都轉人工覆核，不猜值、不算通過。
- 「雙方皆無」（例：無 KI 商品的 KI 欄位）必須由 PDF 明確判斷為不適用，才算通過。
- 報告保留每一項的 Excel 值、PDF 值與 PDF 出處（頁碼、座標）。
