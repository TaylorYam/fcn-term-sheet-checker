# 核對規則：各上手共用

- 決策：[ADR 0009](../adr/0009-shared-rules-defined-per-rule.md)。共用規則只實作一次，語意由本文件逐條定義，不以任何一家上手為準。範本本身的寫法或條款定義不同時，由上手 adapter 宣告（例：範本沒有的欄位交出「不適用」、規則可讀的參考條件表欄位），共用規則照宣告處理，不寫「如果是某家上手」的分支。
- 參考條件表：[參考條件表格式](../order-formats/reference-sheet.md)（設定檔 `config/reference_sheet.toml`，[ADR 0008](../adr/0008-reference-sheet-and-import-format.md)）。
- 標準欄位：`src/fcn_checker/standard_fields.py`；新上手要交出哪些欄位見[新增上手實作規範](../issuer-onboarding.md) §6.2a。
- 會隨時間改變的基準（審查通過日期、固定警語、負責人、名稱格式、面額預設值、費率等）見[審查標準](review-standard.md)；投資人須知的共用規則見[投資人須知核對規則](iis-check-rules.md)。
- 各上手專屬的說明書內部規則見各上手的核對規則文件（`docs/rules/<上手>-check-rules.md`）。
- 本文件的內容原本寫在 [BARC 核對規則](barc-check-rules.md)（§3.4、§3.6、§3.8、§4、§9），2026-10-15 搬出；規則本身沒有改變。

## 1. 判定原則

- 任何必核欄位抓不到、抓到多個不同值、或型態不屬於範本規格列出的寫法，都轉人工覆核，不猜值、不算通過。
- 「雙方皆無」（例：無 KI 商品的 KI 欄位）必須由說明書明確判斷為不適用，才算通過。
- 上手沒交出某個標準欄位（`not_provided`）時，相關規則轉人工覆核並寫出欄位名稱；範本本身沒有的欄位（`absent`，不適用）不比對、不報缺漏。
- 核對紀錄保留每一項的參考條件表值、說明書值與說明書出處（頁碼、座標）。

## 2. 數值處理

- Excel 數字可能有二進位浮點尾數（例：`x.xx64999999994`），先四捨五入到 9 位小數清掉尾數。
- 百分比：依說明書顯示的位數四捨五入後比對。
- 價格：一律四捨五入（half-up）到 4 位後比對。
- 數值一律用 Decimal；日期不猜日月順序。

## 3. 參考條件表欄位（`rules/reference.py`、`backfill.py`）

表上事先填好的欄位與說明書標準欄位比對；回填欄位空白時於通過後回填。

| 參考條件表欄 | 標準欄位 | 規則 |
|---|---|---|
| TDCC Code | `product_code` | 配對＋字串相等 |
| ISIN Code | `isin` | 回填欄位：空白 → 通過後回填；有值 → 比對（`backfill.isin`） |
| 單位面額 | `denomination` | 整數相等；另有審查標準的面額預設值檢查（`doc.denomination`） |
| 承作幣別（或 `計價幣別`） | `currency_zh`、`currency_others` | 依審查標準幣別對照；不在表內轉人工覆核。金額旁的幣別字每處各一筆，= 承作幣別（`field.currency`）。商品幣別不必等於標的幣別（Issue #170） |
| 發行日 | `issue_date` | 回填欄位：空白 → 通過後回填；有值 → 比對（`backfill.issue_date`，Issue #64） |
| 交易日、最終比價日、到期日 | `trade_date`、`final_valuation_date`、`maturity_date` | 日期相等 |
| KO(%)、K(%)、KI(%)、Coupon p.a. (%) | `ko_pct`、`strike_pct`、`ki_pct`、`coupon_pa_pct` | 依說明書顯示位數四捨五入後比對；無 KI 時 KI(%) 必須是 `-` |
| KO(Freq) | `ko_observation` | `D` 期間每日／`P` 每期定日 |
| KO(memo) | `ko_memory` | `Y`／`N` |
| KI(Freq) | `ki_type` | `-` 無／`AM` 到期觀察／`D` 每日觀察／`P` 每期觀察；Monthly KI 轉人工覆核 |
| 天期(月) | `tenor_months` | 整數相等 |
| Non-Call(月) | `autocall_schedule` 的第一個可提前出場期 | 相等（最小為 1） |
| 期初定價 | `initial_pricing` | 表上須是 `開盤價`／`收盤價`／`VWAP`；表上空白時當成不是 VWAP。說明書寫明期初定價的範本（範本沒有就是 `absent`），表上有值時須相同，表上空白時依說明書判斷（Issue #122、#246） |
| UL_1～UL_5 | `underlyings` | 見 §5；`-` 表示沒有這檔標的 |
| UL_n_進場價／執行價／下限價／KO價 | `underlying_prices` | 表上值四捨五入到 4 位後相等。同一檔標的可比對的價格欄全部與說明書差同一比例（表上值 ÷ 說明書值，4 位）且不是 1 時，該檔轉人工覆核並寫出比例（疑為股票分割調整後的價格，`split_suspected`，Issue #191）；只有部分欄位不同或比例不同時照常判不一致。無 KI 時下限價必須是 `-`。期初定價為 `VWAP` 時不比對，通過或人工放行後以說明書價格覆寫（`backfill.underlying_prices`） |
| 最低申購、最低贖回金額 | `min_amounts`（出處清單） | 每一處 = 單位面額（`field.min_amounts`）；倍數依審查標準 `min_amount_multiples.<上手>` |
| 比價日_1～12 | `autocall_schedule` | 回填欄位（`backfill.compare_dates`）。D：`比價日_{Non-Call}` 與 `比價日_{期數}` = 各該期比價日；P：`比價日_{Non-Call}`～`比價日_{期數}` = 各期比價日；其他格 `-`。期數須等於天期、不超過 12；最晚的比價日須等於最終比價日 |
| TS、IIS | — | 回填欄位：說明書與投資人須知都通過或人工放行的商品打 `V`；表上是 `V` 以外的值就是不一致、保留原值（`backfill.checked`） |

## 4. 說明書推算規則（`rules/derivation.py`）

- 各標的執行價、KO 價、下限價 = 期初價格 × 對應百分比，四捨五入（half-up）到 4 位（`derive.prices`）。
- 價格表列數須等於標的數；有無下限價欄須與 KI 型態一致；不符轉人工覆核。
- 期初價格本身沒有外部來源可比，只核對以它推算的各價格。

## 5. 標的

- 只核對彭博代號：說明書代號 = 參考條件表 `UL_1`～`UL_5`，依順序逐一相等，標的數量也要相同。
- 代號含交易所尾碼，逐字比對；尾碼代表交易所，例如 `XXX UW` 與 `XXX UQ` 視為不同標的。
- 標的中文名稱與交易所不核對：上手以代號索引自動帶入名稱，確認代號即可（2026-10-02 使用者確認）。
- 上手可宣告標的不看順序（`config/reference_sheet.toml` 的 `[underlyings] any_order_issuers`），此時依代號配對各標的價格（Issue #265）。

## 6. 共用的日期規則

| 項目 | 規則 |
|---|---|
| 商品開始受理申購日期（`subscription_dates` 出處清單） | 每一處 = 交易日（`doc.subscription_start_date`） |
| 中文產品說明書刊印日期（`print_dates` 出處清單） | 交易日（含）至發行日（不含）之間（`doc.print_date`，#254） |
| 審查通過日期 | = 審查標準 `approval_dates` 中交易日當天或之前最近一次的日期 |
| 提前出場觀察期的期始日（範本定義為「前期期末後的下一個一籃子預定交易日」時） | 跳過週末，也跳過任一標的交易所的休市日（`config/exchange_holidays.toml`，標的市場由彭博交易所碼決定；`kit.period_start`，Issue #208）。標的交易所不在假日表或日期超出涵蓋範圍時，已知市場的休市日照樣跳過；期始日比推算結果晚才轉人工覆核，比推算結果早或落在週末、已知休市日仍是不一致（假日只會讓日期往後延） |

不核對：交易日 → 發行日、最終評價日 → 到期日、評價日 → 支付日的平日間隔（遇假日會變，只作參考）；只有文字定義、沒有具體日期的規則（例：指定提前現金贖回日 = 事件後第三個營業日）。

## 7. 由上手宣告的差異

下列差異來自範本本身的寫法或條款定義，由上手 adapter 宣告或寫在該上手的核對規則文件，共用規則不另外判斷上手：

- **範本沒有的標準欄位**：交出 `absent`（不適用），共用規則不比對、出處清單不產生結果（例：MS 沒有年利率與受理申購日、BBVA 沒有封面發行機構欄）。
- **說明書內部規則可讀的參考條件表欄位**：在上手註冊項目的 `reference_fields` 逐一宣告（目前是年利率，BARC 另加天期），只有說明書印的值是由參考條件表才有的條件推算出來時才宣告（例：月配息率 = 年利率 ÷ 12）。
- **月配息率等推算的捨入與容差**：依該上手範本的寫法（例：BARC 推算值與說明書差 ≤ 0.0001；MS 四捨五入到 4 位後相等），寫在各上手核對規則文件。
- **沒有 KO 欄但仍有自動提前出場機制**（例：MS Non-Call = 天期、SG 無自動提前出場）：adapter 交出 `ko_pct` = 100、各標的 KO 價 = 期初價格，共用規則照常比對（Issue #194、#202）。
- **審查標準的上手差異**：放在 `config/review_standard.toml` 的上手分節，見[審查標準](review-standard.md)。
