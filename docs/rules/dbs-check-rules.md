- 狀態：核對範圍與規則已與作業人員確認（2026-10-15，Issue #280）；已實作（`parsers/dbs.py`、`rules/dbs.py`、`parsers/dbs_iis.py`、`rules/dbs_iis.py`）

## 1. 範圍

- 4 份樣本（DB1–DB4，本機；私有 Repo `fcn-oos-samples` 沒有 DBS）。骨架、標籤、句型相同。
- 說明書（TS）與投資人須知（IIS）在同一張 Issue 處理；投資人須知規則見[投資人須知核對規則](iis-check-rules.md) §3 DBS 欄。
- 核對範圍依開發者凍結清單（Issue #280 探勘留言的 17 題）逐項決定；作業人員決定不畫螢光（2026-10-15）。
- 支援樣態只有 KO 每日觀察＋記憶式、KI 到期觀察或無 KI、非 VWAP、Non-Call < 天期（`[unsupported_variants]`）；其他樣態在辨識時就攔下，本規則不處理。

## 2. 不核對的項目（2026-10-15 確認）

- 沿用 BARC／HSBC／MS／BNP／SG／Citi／JPM／Nomura／GS／Natixis／CA／BBVA：整理表存續或內部欄位、信用評等、發行機構方負責人、財報、匯率、到期贖回價值。
- **發行人**（新加坡商星展銀行股份有限公司台北分公司）名稱、電話、地址（封面、相關機構事業概況 3.、投資人須知相關機構 2.；作業人員決定只核對發行機構名稱）；**保證機構**（`本商品無保證機構。`）。
- **期初定價和說明書的比對**（說明書沒寫開盤價／收盤價／VWAP；`initial_pricing` 交 `absent`，共用規則只檢查表上是允許值）。
- **`UL_n_Memo`**（說明書是整檔判斷記憶式）。
- **封面 `(請參閱第a-b頁)` 的頁碼**（4 份都比實際風險揭露頁早一頁；作業人員決定不核對，自行轉告上手）。
- **觀察起始日**（4 份 = 刊印日期，但條文沒有規定這個關係）。
- 利息金額的四捨五入位數（USD、AUD 兩位、JPY 整數位）；累積日數／總日數（觀察日數比例）。
- Quanto 匯率條款、支付日與營業日城市；價格表與情境股價的幣別字（標的報價幣別，不和承作幣別比，§3.1）。
- 發行機構註冊地、商品註冊地、公會審查；計算代理人、報價機構、保管機構、結算機構；準據法。
- 連結標的中文名稱、交易所（只核對彭博代碼與價格）；連結標的之相關說明、調整條件；投資人須知標的名稱。
- 警語 2～11 的全文（只保留全文禁用語檢查）。
- 情境分析的利息金額、股數、零股金額、總報酬率、情境一／三的年化報酬率、假設匯率、情境一的觀察日序 n（只核對基本假設、情境價格表、情境一期別、情境二年化報酬率，§3.7）。
- 開始／後續受理贖回日期（只有文字；投資人須知也不核對）。
- 商品基本資料 `文件：` 起各項（發行計劃、條款、銷售條件、市場代理人、稅務、FATCA）、提前贖回條件、潛在調整事件、結算干擾、清償、次級市場、律師意見書、銷售限制；相關機構事業概況 2.、3.、5.–10.；商品主要風險揭露（五、1. 固定警語以外）；一般交易事項 3.、5.–7.、9.–17.；特別記載事項與附錄。
- 發行日 − 交易日、到期日 − 定價日的天數（只作參考；到期日和參考條件表比）。

## 3. 核對規則

### 3.1 參考條件表欄位（共用 `rules/reference.py`）

語意與 rule_id 同 BARC。DBS parser 只負責交出標準欄位；來源見 [DBS 下單資料格式](../order-formats/dbs-fcn-reference.md) §2。

### 3.3 配息率（2026-10-15 確認）

| 檢查 | 規則 |
|---|---|
| 年利率 | `最大利率值：…（即y%/12）` 的 y = 參考條件表 `Coupon p.a. (%)`（共用 `field.coupon_pa_pct`） |
| 最大利率值（月配息率） | 同一句的 a = y ÷ 12 **無條件進位（ceiling）到 4 位**（4 份成立；DB2、DB4 無條件進位與四捨五入結果不同） |
| 其他出處 | 情境基本假設 `最大利率值：a%` = a；情境二（於到期最佳情況）`年化平均報酬率約為y%` = 年利率（4 份成立） |
| 第 1～k 期 | `對於第1~k個觀察期間而言，利率為最大利率值`（k = 1 時 `第1個`）的 k = Non-Call；情境基本假設 `利率：第1~k個觀察期間之利率為最大利率值` 的 k 相同 |
| 配息頻率 | 表A 列數 = 天期（每月一期）；不同判不一致（`doc.coupon_periods`） |
| 利息金額位數、累積日數／總日數 | 不核對、不推算 |

### 3.4 價格與百分比

- 共用 `derive.prices`：表1 各標的執行價格／自動提前出場價格／下限觸發價格 = 期初價格 × 百分比，half-up 到 4 位後數值相等（4 份成立，含非整數 K %）；列數 = 標的數；有無下限觸發價格欄與 KI 型態一致。
- **表頭 % 是 K／KO／KI % 的唯一來源**（條文只寫「表1所示依據期初價格的特定比例」）：表1 表頭 = 參考條件表（共用 `field.*`）、= 情境價格表表頭（§3.7）。**欄序 K → KO → KI**，依表頭關鍵字順序決定，不可寫死。表頭讀不到 % → 轉人工覆核。
- 期初價格一律 4 位小數。
- 疑似分割／除權息調整：共用規則（[BNP 核對規則](bnp-check-rules.md) §3.4；樣本沒有這種情形）。

### 3.5 說明書內部交叉驗證（DBS 專屬）

| 檢查 | 規則 |
|---|---|
| 名稱 | 封面 `商品中文名稱` = 商品基本資料 `商品名稱：`（忽略空白、括號全形／半形統一） |
| 商品代號 | 封面 `商品代號` = `受託或銷售機構商品代號` |
| 幣別 | 封面 `計價幣別` = 商品基本資料 `計價幣別`（`{中文}({ISO})`，中文查 `[currency]` = ISO） |
| 期數 | 表A 列數 = 天期 = 名稱 `N個月期`／`N-Month` = 情境基本假設 `商品年期：N個月` |
| KO 型態 | `觀察日：…每一個規劃交易日` ＋ 強制贖回與情境兩處 `自動提前出場決定日…從第k個觀察期間結束日…每一個觀察日`（k 相同）→ D；其他寫法轉人工覆核（範本規格 §4.1） |
| Non-Call | KO 決定日 k = 配息 `第1~k` = 情境基本假設 `第1~k` = 情境一期別 − 1；k < 表A 列數 |
| 記憶式 | `記憶事件：` ＋ `若所有連結標的皆被視為記憶標的` 都有 = Y；其他寫法轉人工覆核（範本規格 §4.2） |
| KI | 到期 `(a)` 寫法、`下限觸發事件：` 定義、表1 有無下限觸發價格欄三者一致（範本規格 §4.4）；名稱 KI 段由名稱樣板核對 |
| 標的 | 連結標的資產表與表1 的代碼、順序、列數相同 |
| 日期表 | 表A 列數 = 天期、期別連續、結束日遞增、結束日 < 同列支付日、末列結束日 = 定價日、末列支付日 = 到期日 |
| 情境價格表 | 情境價格表逐格（期初價格與各價格）= 表1、表頭 % = 表1（§3.7） |

### 3.7 情境分析（`投資收益計算方法…` 的 (3)）

2026-10-15 確認核對：

- 基本假設 `商品年期：N個月` = 天期；`商品面額 = X幣別` = 商品面額；`發行價格 = 100.00%`；`最大利率值：a%` = a；`利率：第1~k個觀察期間…` 與 `自動提前出場決定日：從第k個觀察期間結束日…` 的 k = Non-Call。
- 情境價格表逐格 = 表1（期初價格、執行價格、自動提前出場價格、下限觸發價格；欄序與表頭 % 同表1）。
- 情境一（有利情況）`假設本商品於第j個觀察期間的第n個觀察日發生自動提前出場事件` 的 j = Non-Call + 1。
- 情境二（於到期最佳情況）`年化平均報酬率約為y%` 的 y = 年利率。

不重算利息金額、股數、零股金額、總報酬率、情境一／三的年化報酬率；假設匯率、n 不核對。找不到基本假設或情境價格表 → 轉人工覆核。

### 3.8 最低申購與贖回（2026-10-15 確認）

- 一般交易事項 4. `最低申購金額為m單位商品面額，即X幣別{金額}，並以1單位商品面額為最低加購金額。`：最低申購 = `即` 後的金額，須 = m × 面額；最低加購 = 1 × 面額。
- 8.(3) `最低贖回金額為1單位商品面額，即X幣別{金額}，並以1單位商品面額為累加單位。`：最低贖回、增加贖回單位 = 1 × 面額。
- 新增 `min_amount_multiples.dbs`：`minimum_subscription = { USD = 5, AUD = 7, JPY = 8, CNH = 4 }`（CNH 於 2026-10-16 加入，Issue #296；其他幣別轉人工覆核）、`minimum_additional = 1`、`minimum_redemption = 1`、`redemption_increment = 1`（比照 GS 依幣別）。
