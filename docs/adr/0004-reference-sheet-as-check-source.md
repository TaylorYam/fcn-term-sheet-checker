# 0004: 核對條件統一改用參考條件表

- Status: Accepted
- Date: 2026-10-02

## Context

2026-10-01 曾決定 BARC 停用整理表 `FCN參考條件.xlsx`，改用上手原始詢價表（[fcn-reference-legacy.md](../order-formats/fcn-reference-legacy.md)），HSBC 則暫用新版整理表。2026-10-02 使用者說明：整理表（新版 `FCN參考條件_1001.xlsx` 的 `樣本清單` 工作表）就是核對完成後要匯入資料庫的格式，各標的的進場價、執行價、下限價、KO 價也會先用彭博抓好填入。批量核對（Issue #31）需要一份能涵蓋多家上手、每列一檔商品的條件來源，核對後還要把 ISIN 和比價日回填到同一張表。

## Decision

- 所有上手的核對條件都改用參考條件表（`樣本清單` 工作表）；單筆核對就是只選一份 PDF 的批量核對。（2026-10-14 補充：參考條件表不再限定 `樣本清單` 的固定版面，公司原始的待建檔表也能直接核對：只讀第一張工作表，表頭是前 10 列裡有 `TDCC Code` 的那一列，只檢查必要欄（缺少或重複 → 整批錯誤），其他欄略過；`計價幣別` 與 `承作幣別` 視為同一欄。Issue #199。）（2026-10-14 補充：匯入資料庫的格式改為比照公司原始待建檔表的**匯入格式**（第 1 列最新交易日、第 2 列固定 80 欄），不再是 `樣本清單` 本身；核對結果檔「回填後」改為照匯入格式在新活頁簿重新產生、只帶值與顯示格式，不再刪列重排。原因：作業人員模板與公司原始待建檔表都會拿來核對，原始表的公式、格式化條件、外部連結無法隨刪列安全移動。Issue #203。）
- BARC 詢價表停用，格式文件標示為已停用。CLI 先改用參考條件表；PANEL 暫時保留詢價表流程，PANEL 改用參考條件表時一併刪除詢價表的程式與設定（已於 Issue #46 完成）。
- 說明書以封面商品代號對應表上的 `TDCC Code`，該列的 `發行機構` 也必須是檔名上手編號所對應的上手。（2026-10-14 補充：`發行機構` 改為表上有這欄才確認；公司原始待建檔表沒有這欄，而封面商品代號 = `TDCC Code`、商品代號前三碼 = 檔名上手編號已確定上手。`TS`、`IIS` 也不是必要欄，表上沒有時「回填後」補上並打勾。Issue #199。）
- 工具只回填 `ISIN Code` 與 `比價日_1`～`比價日_12`，其他欄位都由作業人員事先填好，只做核對。回填結果另存新檔，不改原檔。（2026-10-02 補充：`發行日` 也改為回填欄位，Issue #64。）（2026-10-02 補充：不再另存 `_回填_` 新檔，回填結果改放在核對結果檔的「回填後」工作表，只留整份通過的列，Issue #72。）（2026-10-02 補充：作業人員可在 PANEL 人工放行「不一致」或「需人工覆核」的說明書，視同通過並回填；回填值無法確定或回填欄已有不同值時不能放行，Issue #81。）（2026-10-08 補充：參考條件表新增 `期初定價` 欄，作業人員標示 `開盤價`／`收盤價`／`VWAP`，每列必填。`VWAP` 商品的 `UL_n_進場價／執行價／下限價／KO價` 不比對，整份通過或人工放行後一律以說明書價格覆寫，表上原有的值不擋放行。原因：說明書不寫期初價格的定價方式，VWAP 由上手計算、作業人員事先拿不到，上手報的就是最終值，表上沒有比它更權威的來源；上手有沒有算錯仍由「期初價格 × 百分比 = 執行／KO／下限價」與百分比對表核對。曾考慮以價格小數位數或讀說明書判斷 VWAP：說明書沒有可讀的文字，小數位數誤判時會悄悄蓋掉人工填的價格，都不採用。Issue #122。）（2026-10-15 補充：參考條件表的 `期初定價` 常常空白，改為不必填：空白時當成不是 VWAP，各標的價格照常比對。說明書明確寫出期初定價的範本（Citi 標的表表頭「期初評價日之VWAP」）在表上空白時改依說明書判斷，寫 VWAP 就當 VWAP 商品；表上有值時仍以表上為準、和說明書不同判不一致。這只用在範本有明確文字的上手，不推翻前一段「說明書沒有可讀的文字」的判斷。Issue #246。）

## Alternatives considered

- 維持各上手原始詢價表：每家格式不同，一筆交易一個檔，無法直接批量處理，也不是資料庫的匯入格式。
- 批量用參考條件表、單筆仍用 BARC 詢價表：要維護兩套條件來源與對照規則，同一檔商品可能因入口不同而得出不同結論。

## Consequences

- 各上手共用一套參考條件表的欄位對照；BARC 的保證配息期改為核對 `Non-Call(月)`，不再核對 Effective Date offset，改為核對各標的價格；說明書內部的檢查與審查標準規則不受影響。
- 核對品質取決於作業人員事先填表的正確性；表上缺少的條件只能核對說明書內部一致性。
- 參考條件表欄位結構一旦改版，需要同時調整讀取設定與本 ADR 引用的格式文件。
