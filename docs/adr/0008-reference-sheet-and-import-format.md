# 0008: 參考條件表是唯一的核對條件來源，核對結果以匯入格式輸出

- Status: Accepted
- Date: 2026-10-15
- 取代 [ADR 0004](0004-reference-sheet-as-check-source.md)

## Context

[ADR 0004](0004-reference-sheet-as-check-source.md)（2026-10-02）決定所有上手改用參考條件表當核對條件來源。之後兩週累積了 8 段補充，內容包括：
- 回填欄位多了發行日、TS、IIS 與 VWAP 商品的價格欄。
- 新增人工放行。
- 期初定價先改成每列必填，後來又改成可空白。
- 參考條件表可以直接用公司原始的待建檔表。
- 「回填後」改照匯入格式重新產生。

本文的決定（「`樣本清單` 工作表」「只回填 ISIN 與比價日」「期初定價每列必填」）已經被補充一一改掉，讀者要看完整份才知道現況。本 ADR 把目前有效的決定寫成一份，取代 0004；各段補充的原因保留在 0004 與對應 Issue。

## Decision

- **唯一的核對條件來源**：作業人員事先填好的參考條件表（Excel）是所有上手唯一的核對條件來源；說明書與投資人須知是被核對的文件。上手原始詢價表停用（Issue #46）。
- **怎麼讀表**：只讀第一張工作表，依欄名找欄，只檢查必要欄（所有要核對的欄，加上表上有值時也要核對的回填欄位）。少欄或欄名重複時整批不核對；其他欄略過。`計價幣別` 與 `承作幣別` 視為同一欄。版面細節見[參考條件表格式](../order-formats/reference-sheet.md)（Issue #199）。
- **配對**：封面商品代號 = `TDCC Code`。表上有 `發行機構` 欄時，另外確認該列屬於檔名上手編號對應的上手；沒有這欄就跳過，因為商品代號前三碼已經確定上手。
- **回填欄位**：只有 `TS`、`IIS`、`ISIN Code`、`發行日`、`比價日_1`～`比價日_12` 由工具回填。`ISIN Code`、`發行日`、比價日空白時通過後回填，有值時比對；`TS`、`IIS` 在說明書與投資人須知都通過或人工放行時打 `V`，表上是 `V` 以外的值就是不一致（Issue #127）。期初定價為 `VWAP` 的商品，各標的的 `UL_n_進場價／執行價／下限價／KO價` 也是回填欄位，一律以說明書的值覆寫（Issue #122）。其他欄位都由作業人員事先填好，工具只核對。
- **期初定價**：`期初定價` 欄可以空白，空白時當成不是 VWAP，各標的價格照常比對。只有說明書明確寫出期初定價的範本（例：Citi 標的表表頭「期初評價日之VWAP」），表上空白時才依說明書判斷；表上有值時以表上為準，和說明書不同判不一致（Issue #246）。VWAP 由上手計算，作業人員事先拿不到，所以上手報的就是最終值；上手有沒有算錯，仍由「期初價格 × 百分比 = 各價格」與百分比對表核對。
- **不改原表**：核對後只產生一份核對結果檔，內含「回填後」與「錯誤清單」兩個工作表。「回填後」照**匯入格式**（比照公司原始待建檔表，設定檔 `[import_format]`）在新活頁簿重新產生，只帶值與顯示格式；只留說明書與投資人須知都通過或人工放行的列（Issue #72、#203）。
- **人工放行**：作業人員看完一份「不一致」或「需人工覆核」文件的全部錯訊後，可以在 PANEL 放行，視同通過並回填。下列情況不能放行（Issue #81）：
  - 回填值無法確定。
  - 參考條件表回填欄位已有不同的值（VWAP 覆寫的價格欄除外）。
  - 配對有問題。

## Alternatives considered

- **各上手原始詢價表**：每家格式不同，一筆交易一個檔，無法批量處理，也不是資料庫的匯入格式。
- **批量用參考條件表、單筆仍用 BARC 詢價表**：要維護兩套條件來源，同一檔商品可能因入口不同而得出不同結論。
- **在原表上刪列重排成「回填後」**：公司原始待建檔表的公式、格式化條件與外部連結無法隨刪列安全移動（Issue #203）。
- **以價格小數位數或說明書文字判斷 VWAP**：多數說明書沒有可讀的文字；小數位數誤判時會悄悄蓋掉人工填的價格（Issue #122）。

## Consequences

- 各上手共用一套參考條件表欄位對照與規則，定義見[共用核對規則](../rules/shared-check-rules.md)（[ADR 0009](0009-shared-rules-defined-per-rule.md)）。
- 核對品質取決於作業人員填表的正確性；表上缺少的條件只能核對說明書內部一致性。
- 參考條件表或匯入格式改版時，要同時調整設定檔（`config/reference_sheet.toml`）與[參考條件表格式](../order-formats/reference-sheet.md)。
- 投資人須知怎麼和參考條件表、同商品說明書比對見 [ADR 0007](0007-iis-paired-with-term-sheet.md)。
